# knowledge — チーム共有ナレッジベース

特定チャンネルに閉じない、横断的に使えるYouTube運用ナレッジを蓄積する場所。

## 何を置くか
- アルゴリズム理解
- 台本構成パターン
- サムネ・タイトルのCTR設計知見
- AI活用（プロンプト集・ツール選定）
- 収益化・規約・著作権
- アナリティクス読み解き方

## 何を置かないか
- 特定チャンネル固有の戦略 → `channels/{name}/`
- 担当者個人の振り返り → 各人のプロファイル or 議事録

## 運用ルール
- 知見が溜まったらyutakaが整理・統合する
- チャンネル間で再利用された手法は必ずここに昇格させる
