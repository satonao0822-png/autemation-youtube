# YouTube Analytics 読み解きガイド

## まず見るべき指標（動画単位）
1. **インプレッションCTR** — サムネ・タイトルの強さ
2. **平均視聴維持率（%）** — コンテンツの引きの強さ
3. **平均視聴時間（分）** — 尺との相性
4. **離脱グラフ** — どこで視聴者が消えたか

## 改善仮説の立て方

| 症状 | 仮説 | 打ち手 |
| --- | --- | --- |
| CTR低い | サムネ/タイトルが弱い or ターゲットずれ | サムネA/B、タイトル書き直し |
| 序盤離脱が多い | フックが弱い | 0:00〜0:30を作り直す |
| 中盤離脱 | 冗長 / 期待値ずれ | チャプター再構成、カット |
| 終盤離脱 | 結論前に満足 / CTA直前で離脱 | 結論を後ろに、CTAは自然に |
| 維持率は高いがCTR低い | コンテンツは良い → 露出問題 | サムネ刷新 |

## チャンネル単位で見る指標
- **総再生時間（時間/月）** — 収益化条件・成長指標
- **登録者増加数** — どの動画が登録に効いたか
- **トラフィックソース** — ブラウジング機能 / 関連動画 / 検索の比率
- **ユニーク視聴者数 vs 再帰視聴率** — ファン化度合い

## レビュー頻度
- 動画単位: 公開24h・72h・1週・1ヶ月
- チャンネル単位: 週次 / 月次
