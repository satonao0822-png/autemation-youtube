# 日次HQブリーフィングフロー

> **1日1回**、[非属人YouTube HQ](https://www.notion.so/3729aee02088813a9b5fc24894468629) 先頭の **「📣 なーたんへの今日の活動内容報告」** を更新する。

## データの流れ

```
日中: meetings/*.md（議事・決定の正本）
        ↓ 都度（任意）
      日次活動サマリー（セッション細ログ）
        ↓ 1日1回・終業時
      日次HQレポート（なーたん向け要約）← HQ最上部ビュー
```

## Notion DB

| DB | URL |
| --- | --- |
| **日次HQレポート** | https://www.notion.so/4dc69eca0d454576b585d4ff1ee332d5 |

### プロパティ

| 項目 | 用途 |
| --- | --- |
| 報告名 | `YYYY-MM-DD 日次報告` |
| 日付 | 報告対象日 |
| **なーたんへの報告** | 3〜5行のエグゼクティブサマリー（最重要） |
| 議事・決定サマリー | 議事録・ADRの要約 |
| **チーム活動サマリー** | yutaka / PM / hina / nishi … 人格別の箇条書き |
| 次の日の焦点 | 明日やること |
| ローカル議事録 | `meetings/` `decisions/` パス |
| 関連活動ログ | 日次活動サマリーへの RELATION（任意） |
| ステータス | 下書き → 確定 |

## 終業時の手順（Claude Code / Cursor）

1. 当日の `meetings/YYYY-MM-DD_*.md` を読む
2. 当日の **日次活動サマリー** を確認（あれば統合）
3. Notion で **日次HQレポート** を search（日付=今日）
4. **既存行を update** または **新規 create**（1日1行）
5. 採用した ADR があれば **意思決定** DB にもミラー
6. なーたんに「HQ日次報告を更新した」と1行報告

## チーム活動サマリーの書き方

人格ごとに1行以上。動きがなければ「本日は待機」と明記。

```text
・yutaka: …
・投資チャンネルPM: …
・恐竜チャンネルPM: …
・manami: …
・nishi: …
・junki: …
・hina: …
```

## HQ ページの見え方

- ページ先頭: **📣 なーたんへの今日の活動内容報告**（見出し + リンク）
- 直下: リンクドビュー **「📣 なーたんへの今日の活動報告」**（日付降順）
- **初回のみ**: ビューをページ最上部にドラッグして固定推奨

## ローカルとの対応

| ローカル | Notion |
| --- | --- |
| `meetings/YYYY-MM-DD_*.md` | 議事・決定サマリーに要約 |
| `decisions/ADR-*.md` | 意思決定 DB + 日次HQに1行 |

議事録の**全文**はローカルに置き、Notion には**要約のみ**。
