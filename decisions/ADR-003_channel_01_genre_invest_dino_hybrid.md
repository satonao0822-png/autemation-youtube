# ADR-003: channel_01ジャンル選定 — 投資×恐竜の2チャンネルハイブリッド方針

- **日付**: 2026-06-01
- **ステータス**: 採用（Accepted）
- **決定者**: なーたん
- **起案**: yutaka
- **関連**: [ADR-001](ADR-001_team_structure.md) / [ADR-002](ADR-002_ops_team_formation.md) / [ADR-004](ADR-004_invest_channel_target_and_revenue.md)
- **議事録**: `meetings/2026-06-01_genre_research.md`

## 背景

- 2026年は YouTube の Inauthentic Content ポリシー強化下にあり、AI faceless チャンネルは「人間の編集判断と独自視点」が無いと一網打尽でデモネタイズされる環境。
- 一方、ツール環境（Seedance 2.0、Fish Audio S2 等）は揃っており、「AIをツールに、人間が企画・編集する」モデルなら勝負できる。
- 立ち上げ第一弾チャンネルとして、yutaka が5案（A:新NISA投資 / B:AIツール / C:シニア健康 / D:インバウンド英語 / E:ビジネス偉人）を提示。
- なーたんから「サッカー（W杯短期）」「恐竜（情熱・大人向け古生物）」という追加ジャンルが提案され、収益性と情熱の両立が論点となった。

## 選択肢

| 案 | 内容 | 評価 |
| --- | --- | --- |
| α | 投資1本に集中（収益最優先） | 収益最大化だが、なーたんの情熱領域でない / 半年で疲弊リスク |
| β | サッカー+恐竜の情熱2本立て | 情熱は満たすがW杯は短命、サッカーは権利リスク、恐竜単独は収益弱い |
| **γ** | **投資メイン + 恐竜サブ** | **収益エンジンと情熱領域の両立、リスク分散、海外展開余地** |
| δ | 投資+AIツール（高収益2本立て） | 全部高収益だが、なーたんの愛着がない |

## 決定

**γ案 採用**:

- **メインチャンネル**: `channels/channel_01_invest_youth/` — 投資チャンネル（収益エンジン）
- **サブチャンネル**: `channels/channel_02_dinosaur/` — 大人向け恐竜・古生物解説（情熱領域 / 長期資産 / 海外展開の実験機）
- **サッカー**: W杯短期スポット枠は **当面見送り**（恐竜サブ枠とリソース競合するため、長期資産側を優先）

### リソース配分

- 投資 : 恐竜 = **7 : 3**（量・予算とも）
- 投資チャンネルが先行（先に台本3本着手）、恐竜はSeedance品質検証から開始

## 結果（Consequences）

### ポジティブ

- **リスク分散**: 投資は収益性、恐竜は持続性と海外CPM。片方が落ちても全損しない。
- **情熱と収益の両立**: なーたんの興味（恐竜）にチームの稼働余力を組み込むことで、半年〜1年スパンの継続性が担保される。
- **学びの横展開**: 投資（日本語・短期収益）と恐竜（学術寄り・海外展開）は性質が真逆。両方回すことで faceless 運用ナレッジが厚くなる。
- **海外展開オプション**: 恐竜は最初から画像・図解を言語非依存に設計し、後で英語AI音声に差し替えるだけで海外版を立てられる。

### ネガティブ・リスク

- **リソース2分割**: チーム4人で2チャンネル並行はタイト。初期は投資先行・恐竜は週次の品質検証のみに絞る。
- **初期投資コストの増加**: Seedance Pro $69.9 + Fish Audio有料 で **月15,000〜20,000円** は最低必要。恐竜の海外展開フェーズで Fish Audio の英語クレジットを追加するとさらに上乗せ。
- **収益化までの期間**: 恐竜単体での収益化は半年以上覚悟。投資側の収益で恐竜を支える構造。

## 将来の見直しトリガー

- 投資チャンネルが3ヶ月で登録1000・4000時間に届かなければ、ターゲット・トーン・企画ストックの大幅見直し（ADR-005以降で起案）。
- 恐竜チャンネルが6ヶ月で月1万再生に届かなければ、英語版前倒し or 撤退判断。
- W杯本戦期（2026年6月）に短期スポット枠を再検討する余地は残す（別ADRで議論）。
