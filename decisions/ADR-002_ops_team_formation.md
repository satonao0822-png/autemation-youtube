# ADR-002: YouTube運営チーム（manami / nishi / junki / hina）の編成

- **日付**: 2026-06-01
- **ステータス**: 採用
- **決定者**: なーたん
- **起案**: なーたん

## 背景
ADR-001でyutakaを単独のYouTube責任者として置いたが、量産体制を回すには制作工程ごとの専門職が必要。
非属人YouTubeの基本工程は「リサーチ・台本 → 映像 → 編集（音声合成含む）→ サムネ」に分解できるため、これを職能別エージェントとして編成する。

## 選択肢
- **A**: 工程ごとに専門エージェントを置く（職能別チーム）
- **B**: チャンネルごとに専属PMを置く（チャンネル別チーム）
- **C**: yutakaが全工程を直接担当（現状維持）

## 決定
**A: 職能別チーム** を採用。yutaka配下に4人を配置：

| 名前 | 役割 |
| --- | --- |
| manami | YouTube作家（リサーチ・台本） |
| nishi | 映像クリエイター（seedance等で映像生成） |
| junki | 編集（fish audio等で音声合成、字幕、最終仕上げ） |
| hina | サムネ / タイトル設計 |

### 採用理由
- **再現性**: チャンネル横断で同じパイプラインを使える
- **専門性**: 工程ごとにナレッジが深まる
- **量産性**: 複数チャンネル並走時にもスケールしやすい
- **当面の規模感**: チャンネル数1〜数本なら専属PMより職能別の方が効率的

### コミュニケーション方針
- ピア間で直接 `Agent` 呼び出し可。yutakaを毎回経由しない。
- 詳細は `team/communication_protocol.md`。

## 結果
- `.claude/agents/{manami,nishi,junki,hina}.md` 配置済み
- `team/{name}_profile.md` 配置済み
- `team/communication_protocol.md` 配置済み
- yutakaの定義を更新（部下管理セクション追加）

## 将来の見直しトリガー
- チャンネル数が3本を超え、各チャンネルの差別化のためにPM的役割が必要になったら、ADR-003で専属PM追加を検討
- 各工程のボトルネックが顕在化したら、職能内の分割（例: 編集→粗編集 + 仕上げ）を検討
