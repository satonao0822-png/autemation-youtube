# ADR-005: チャンネル別PMレイヤーの新設（投資チャンネルPM / 恐竜チャンネルPM）

> 注: 当初は個人名（akari / souta）で起案・採用したが、同日中に命名規則を整理し、役割名（投資チャンネルPM / 恐竜チャンネルPM）に統一した。本文中の呼称は新呼称に書き換え済み。経緯は文末の「追記: 命名規則変更」を参照。

- **日付**: 2026-06-01
- **ステータス**: 採用（Accepted）
- **決定者**: なーたん
- **起案**: yutaka
- **関連**: [ADR-001](ADR-001_team_structure.md) / [ADR-002](ADR-002_ops_team_formation.md) / [ADR-003](ADR-003_channel_01_genre_invest_dino_hybrid.md) / [ADR-004](ADR-004_invest_channel_target_and_revenue.md)

## 背景

- ADR-002 で yutaka 配下に職能メンバー4人（manami / nishi / junki / hina）を編成済み。yutaka が両チャンネルのPMを兼務する想定だった。
- ADR-003 で投資×恐竜の2チャンネルハイブリッド運用が決定。
- なーたんから「投資系チャンネルと恐竜のチャンネルで、動画の作り方違うと思うから、ファイルを分けて、その中に各チャンネルのPMをおいてください」との指示。
- 実態として、両チャンネルは以下のように**運用ノウハウが本質的に異なる**：

| 軸 | 投資チャンネル | 恐竜チャンネル |
| --- | --- | --- |
| 制作頻度 | 週複数本（量産前提） | 週1本（じっくり） |
| 主なガードレール | 金融広告コンプラ・投資助言NG表現 | 学術的正確性・憶測の排除 |
| 編集スタイル | 図解スライド主体、テンポ早め | BBC Earth風しっとり、10-15分尺 |
| 主収益 | 口座開設アフィリ（即効性） | 広告RPM・書籍アフィリ・英語版（長期） |
| 判断軸 | CTR / 口座開設CR / コンプラ | 学術精度 / 平均視聴時間 / 海外視聴比率 |
| 横展開 | 国内特化 | 英語版前提の素材設計 |

- yutakaが兼務すると、戦略・対外・なーたん窓口の役割と、現場の細かい編集ガードレール運用が同居して非効率。両チャンネルの異なる判断軸の切り替えで認知負荷が高い。

## 選択肢

| 案 | 構成 | メリット | デメリット |
| --- | --- | --- | --- |
| (a) | yutaka が両ch兼務（現状維持） | レイヤー増えず単純 | 現場ガードレールがブレる・yutakaがボトルネック化 |
| **(b)** | **各chに専任PMを置く（投資チャンネルPM / 恐竜チャンネルPM）** | **判断軸を分離・現場ノウハウが各PMに蓄積** | レイヤー増・呼び分けルール整備が必要 |
| (c) | 各chに兼業フリーランスPMを実際に雇う | プロが入る | コスト発生・本案件の規模感に合わない |

## 決定

**(b) 各チャンネルに専任PMエージェントを新設**。

### 新PMの定義

| PM呼称 | 内部slug | 担当チャンネル | キャラクター背景 | 主担当領域 |
| --- | --- | --- | --- | --- |
| **投資チャンネルPM** | `invest-pm` | `channels/channel_01_invest_youth/` | マネー系FP上がり・元証券Webマーケ。明るくテンポ早い敬体、コンプラ違反は即差し戻し、数字で会話する | 金融広告コンプラ・口座アフィリ導線・編集判断ログ運用・週次KPI監視・量産パイプライン維持 |
| **恐竜チャンネルPM** | `dinosaur-pm` | `channels/channel_02_dinosaur/` | 元・科学系出版編集者。落ち着いた敬体、一次情報主義、長期視点 | 学術精度・Seedance品質判定・英語版素材設計・長期ライブラリ資産設計・月次KPI監視・本格運用GO条件管理 |

### yutaka との責任分界

- **yutaka**: 戦略・対外・なーたんへの最終報告・ADR起案・チャンネル横断ナレッジ統括・予算と体制
- **投資チャンネルPM / 恐竜チャンネルPM**: 担当チャンネルの現場運営・編集ガードレール・KPI監視・チーム内タスク捌き・公開可否（コンプラ・学術精度レベル）

明確化するなら：
- 「ターゲット変更したい」「収益構造を見直したい」「新ジャンル開拓」→ yutaka
- 「EP02のこの表現コンプラ大丈夫？」「Seedanceのこのカット使える？」→ PM（投資チャンネルPM / 恐竜チャンネルPM）

### 配下メンバーの扱い

- manami / nishi / junki / hina は**チャンネル横断・職能特化のまま**。
- 各PMが「自分の担当チャンネルの仕事」として4人に依頼する形。
- メンバー間ピアコミュニケーション（ADR-002）は維持。PMは介入が必要なときだけ入る。
- リソース被りは投資チャンネルPM と 恐竜チャンネルPM の週次擦り合わせで調整。両者で割れたらyutakaが裁定。

### ファイル構成

- サブエージェント本体: `.claude/agents/invest-pm.md` / `.claude/agents/dinosaur-pm.md`
- 詳細プロファイル: `team/channel_managers/invest-pm.md` / `team/channel_managers/dinosaur-pm.md`
- 各チャンネルREADMEの冒頭に「このチャンネルの担当PM」セクションを追加
- 組織図: `team/org_chart.md` を新規作成
- CLAUDE.md の人格テーブルにPM2人を追記
- 命名規則: `team/naming_convention.md`（PM呼称統一の根拠）

## 結果（Consequences）

### ポジティブ
- yutakaが戦略・対外に集中できる。なーたんへの報告品質が上がる。
- 各チャンネルの判断軸が分離され、ガードレール運用が安定する（特に金融コンプラと学術精度）。
- 現場ノウハウがPM単位に蓄積される（投資チャンネルPMに金融コンプラ、恐竜チャンネルPMに学術精度・英語版運用）。
- なーたんからチャンネルごとに直接 `Agent` で指名できる（「投資チャンネルPM、EP02どう？」「恐竜チャンネルPM、Seedanceどう？」）。

### ネガティブ・リスク
- 人格が増えたことで、なーたん側の呼び分け負荷が若干上がる → `team/org_chart.md` の呼び分けルール表＋`team/naming_convention.md` で軽減（PMを役割名にしたことで覚えるべき固有名は6つに固定）。
- PMと職能メンバーの責任境界が曖昧化するリスク → 各PM定義に「責任分界」セクションを明記済み。
- 2chの運用差が拡大すると、横展開ナレッジが分断しやすい → yutaka が `knowledge/` への昇格を意識的に行う。

## 将来の見直しトリガー

- 3ヶ月運用後、PMレイヤーがボトルネックになっていないか確認。スルーされているなら不要と判断。
- 新規チャンネル（例: 恐竜の英語版 / 投資の隣接領域）を立ち上げる際は、既存PM増配 or 新PM新設を都度判断（命名は `{ジャンル}-pm` テンプレに従う）。
- PM2人の人格が安定したら、両者で共通する運用パターンを `knowledge/pm_playbook.md` 等に昇格させる。

## 追記: 命名規則変更（2026-06-01 同日）

当初本ADRは個人名（akari / souta）で起案・採用したが、なーたんから「個人名が増えすぎると分別しにくくなる。PMは役割名でいい」との指摘を受け、同日中に命名規則を整理。

- 旧呼称: akari（あかり）/ souta（そうた）
- 新呼称: 投資チャンネルPM / 恐竜チャンネルPM
- 内部slug: `invest-pm` / `dinosaur-pm`

意思決定の本質（PMレイヤーを新設してyutakaから現場運営を委譲する）は変更なし。**呼称のレイヤーを「個人名（属人的職能） vs 役割名（管理ロール）」で整理した**のがアップデートポイント。

命名規則の全体像は `team/naming_convention.md` に明文化。本ADRおよび関連ドキュメントの本文は新呼称に書き換え済み。キャラクター背景（FP上がり / 元出版編集者）は判断軸として保持。
