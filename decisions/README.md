# decisions — 意思決定ログ（ADR）

重要な意思決定を後から追跡できるように、ADR (Architecture Decision Record) 形式で記録する。

## ファイル命名
`ADR-{連番3桁}_{slug}.md`

例: `ADR-001_team_structure.md`

## テンプレート

```markdown
# ADR-XXX: タイトル

- **日付**: YYYY-MM-DD
- **ステータス**: 提案中 / 採用 / 撤回 / 上書き済み（→ ADR-YYY）
- **決定者**: なーたん
- **起案**: yutaka / 担当者名

## 背景
何が起きていて、なぜ決定が必要か。

## 選択肢
- A: ...
- B: ...
- C: ...

## 決定
採用した案と理由。

## 結果
予想される影響・トレードオフ。

## 関連
- 他のADR、ファイル、議事録へのリンク
```

## ルール
- 決定はその場で記録（後回しにしない）
- 撤回・更新はステータスを書き換え、新ADRを発行
- 1ファイル = 1決定
