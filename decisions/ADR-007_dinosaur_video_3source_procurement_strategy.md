# ADR-007: 恐竜チャンネル映像3ソース調達戦略の採用

- **日付**: 2026-06-04
- **ステータス**: 採用（Accepted）
- **決定者**: なーたん
- **起案**: yutaka（戦略責任者）
- **関連**: [ADR-003](ADR-003_channel_01_genre_invest_dino_hybrid.md) / [ADR-005](ADR-005_channel_pm_layer.md) / [ADR-006](ADR-006_dinosaur_channel_tone_pivot.md)

## 背景

- 恐竜チャンネル（`channels/channel_02_dinosaur/`）EP01 制作開始にあたり、**映像調達コストと品質のバランス**を本番運用フローとして固める必要が生じた。
- 2026-06-04 になーたんから原価設計ブリーフが共有された（`_brief_from_naatan_video_cost_2026-06-04.md`）。主旨は「無料ストック 25% + Magnific 35% + Seedance 40%」の3ソース構成、GPT Image 2 によるマスター設定画 → Seedance I2V のパイプライン、再利用テクニックによるコスト圧縮。
- 恐竜チャンネルPM・yutaka で並行レビューし、ブリーフ内に矛盾点・確認事項を6点整理した上でなーたんに上申。なーたんから「フル採用・恐竜chに限定・Seedance本格運用は素材揃ってから・Magnific は契約済み月1000円プランで継続」の決裁が降りた。
- yutaka 当初の戦略評価（`team/yutaka_review_naatan_brief_video_cost_2026-06-04.md`）では「**部分採用＋段階導入**」を推奨していたが、なーたんが「恐竜chでフロー固めきってから別ch展開」という明確な方針を出したため、フル採用に切り替えた。

## 選択肢

| 案 | 内容 | 評価 |
| --- | --- | --- |
| (a) | 既存の無料ストック中心運用を維持。Magnific/Seedance は将来検討 | コスト最小だが、ADR-006 で確定した「大人の雑学系」トーンを成立させる絵作りが弱い。差別化困難。 |
| (b) | yutaka 当初案: Magnific を先行採用、Seedance は EP03 以降に段階導入 | リスクは低いが、恐竜chで運用フローを固めきってから他ch横展開、というなーたんの戦略意図とズレる。Seedance プロンプト設計・運用ノウハウの蓄積が遅れる。 |
| (c) | 3ソース戦略フル採用（無料ストック 25% / Magnific 35% / Seedance 40%）。ただし Seedance API 課金スタートは台本・音声・素材が揃ってから | なーたんの方針と一致。先行整備（プロンプト設計・ワークフロー設計）で運用知見を蓄積でき、本格運用GO後すぐ立ち上がる。ADR-006 のトーンを成立させる絵作りも担保。 |

## 決定

**(c) 3ソース戦略フル採用** を採用する。

### 採用内容

- 恐竜チャンネルの映像調達を以下の3ソース構成で実施する。
  - **無料ストック 25%**（Pexels / Pixabay 等。地球・宇宙・植生・水中など汎用カット）
  - **Magnific 35%**（既契約サブスク、月約1000円プラン。アップスケール・スタイル変換・ディテール補強）
  - **Seedance 40%**（I2V による主役カット生成。5-8秒クリップ単位）
- 一貫性ワークフロー: **GPT Image 2.0 でマスター設定画を生成 → Seedance I2V で動画化 → 5-8秒クリップに切り出し**。キャラ・環境の一貫性はマスター設定画で担保する。
- 再利用テクニック（速度変更・ズーム・反転・カラーグレード差し替え・テロップ差し替え）で 1 ユニーク生成あたり複数カットを派生させ、原価を圧縮する。

### 適用範囲

- **恐竜チャンネルのみ**。投資チャンネル（`channel_01_invest_youth`）および将来チャンネルは本ADRの適用対象外。
- なーたん明言「恐竜のチャンネルの運用フローを固めきった方が、後から別のチャンネルを立ち上げたい時にすぐできる」。恐竜chで運用ノウハウを確立してから他chへの展開可否を別途判断する。

### 運用前提・制約

- **Seedance 本格運用GO条件**: 台本・音声・素材（マスター設定画含む）が揃ってからAPI課金スタート。それまでは「3ソース全体を先行で動かす」（プロンプト設計・ワークフロー設計・テスト生成）を進めてよい。
- **Magnific**: なーたん名義で契約済み・月約1000円プランで運用継続。固定費として恐竜ch全体に分散。
- **動画尺**: 8〜10分の範囲で散らす（恐竜チャンネルPMがテーマに応じて判断）。固定尺にしないことで複製コンテンツ判定リスクを回避し、テーマの密度に応じた最適化を許容する。
- **月予算枠制は導入しない**。1本ごとの個別承認運用とし、1本あたり1万円を超えない想定で進める。1万円承認ルール（プロジェクト共通）は引き続き適用。

## 結果（Consequences）

### ポジティブ

- 1本あたり現金支出見込み: 約 **5,000円**（Seedance 主役カット + GPT Image 2 キーフレーム生成）。Magnific サブスク月1000円は固定費として恐竜ch全体に分散。
- 複利効果: 再利用ライブラリ（マスター設定画・素材クリップ）が育つほどユニーク生成が減り、10本目以降は **2,500〜3,500円/本** まで圧縮の見込み。
- ADR-006 で確定した「大人の雑学系」トーンを支える絵作り（落ち着いた古生物描写・ふしぎ感のあるビジュアル）が、無料ストック単独では難しかったレベルで成立する。
- 投資チャンネルの本格運用を待機する代わりに、恐竜chの運用フローを早期確立できる。横展開時に Seedance プロンプト設計・ワークフロー設計を流用可能。

### ネガティブ・リスク

- **リスク1: フリー素材のライセンス遵守失敗** — Pexels / Pixabay 等の利用規約は商用利用可否・クレジット要件がソースごとに異なる。**素材ごとのライセンス確認を運用必須項目化**（恐竜チャンネルPM管轄、品質チェックリストに組み込み）。
- **リスク2: Magnific / GPT Image 2 のサービス変更・廃止** — 外部サービス依存リスク。代替案（他アップスケーラー・他画像生成サービス）を事前検討（恐竜チャンネルPM管轄）。
- **リスク3: Seedance 採用率が想定（45〜55%）に届かない** — I2V の品質が安定せずリテイクが嵩む可能性。**リテイク 2.5 倍の予算織り込み済み**で対応。実採用率が大きく下振れたら配分見直し。
- **リスク4: マスター設定画の GPT Image 2 依存** — サービス廃止時にキャラクター・環境の復元手順が失われる懸念。**マスター設定画の生成プロンプト・参照画像をローカル保存**し、別サービスでの再現手順を別途用意する（恐竜チャンネルPM管轄）。

### ADR-006 との接続

- ADR-006 で確定した「大人の雑学系」トーン・「もっと知りたい余韻」「ふしぎ感」のビジュアル翻訳を、本ADRの3ソース戦略が**実行レイヤーで担保**する。
- ADR-006 が「何を見せたいか」を決め、本ADRが「どう調達するか」を決める関係。両者は連動して恐竜chの世界観を成立させる。

## 将来の見直しトリガー

- EP01〜03 公開後、実際の原価実績が想定（5,000円/本）を大きく上回った場合、配分または採用ソースを見直す。
- Seedance 採用率が EP03 時点で 30% を下回る／70% を上回る場合、配分を再設計する。
- 恐竜chで運用フローが固まった段階で、投資ch・将来チャンネルへの横展開可否を別ADRで判断する。
- Magnific / GPT Image 2 のいずれかがサービス変更・大幅値上げ・廃止となった場合、代替ソースへの切り替えを別ADRで判断する。
