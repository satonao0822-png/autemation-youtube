## コンテキスト

### 1. なーたんからの方針提示（2026-06-09）

> 「ショートをある程度運用してフォロワーを獲得しつつ長尺を試験的にスタート」
> 「全く同じで（=既存パイプライン構造・素材ライブラリ・トーン・ペルソナを流用したい）」

**読み解き**:
- 主軸は Shorts。長尺は「試験的に並行」であり、メインの量産対象ではない（少なくとも Phase 1 では）。
- 既存資産（パイプライン・ライブラリ・トーン・ペルソナ）は最大限流用したい。
- ゼロから新チャンネルを立てる発想ではなく、**現在の `channel_02_dinosaur` を Shorts 主軸に組み替える**意向と解釈。

### 2. これまでの前提（変更を要する箇所）

| 項目 | これまで | これから |
| --- | --- | --- |
| 動画形態 | 横型 16:9 / 8-10分 | **縦型 9:16 / 45-60秒**（主） + 横型 8-10分（実験） |
| 主投稿頻度 | 週1本（長尺） | **週4-6本（Shorts）** + 月1-2本（長尺・実験） |
| ノーススター | 平均視聴維持率 | **Shorts 視聴維持率 + ループ率 + フォロワー獲得速度** |
| 構成 | 7パート 8-10分 | **3パート 45-60秒**（フック→展開→締め） |
| EP01 計画 | トリケラ求愛 9:30尺 | Shorts へ翻案 or 長尺第1弾保留（§8 で論点整理） |

### 3. 戦略転換の論拠

- **チャンネル登録者ゼロからのコールドスタート問題**: 長尺 YouTube はサムネCTR × 視聴維持率の二段関門で、登録者ゼロから単発長尺が伸びる確率は経験的に低い。**Shorts は登録者ゼロでも「視聴維持率 + ループ率 + 完了率」のフィードでアルゴ供給される**ため、フォロワー獲得の初速が出やすい。
- **恐竜ジャンルの Shorts 適性**: 恐竜は「ビジュアル即訴求 × 雑学1ネタ完結 × 子供から大人まで関心がある」要素を持つ。Shorts のフォーマット（縦型・短尺・1ネタ）と相性が良いジャンル（推測です。国内事例の系統的検証は §8 のヒアリングで補足）。
- **既存資産の再利用効率**: Magnific の 46本素材は汎用環境素材中心。**縦クロップで Shorts にも流用可能**。ナレーター人格・トーン・ban_avoidance ルールも丸ごと流用できる。Shorts 化のために捨てるものは少ない。
- **長尺リスクの回避**: 長尺で BAN リスク（重複コンテンツ判定・著作権・AI開示）を全部抱え込むより、Shorts で先に「単発が当たるか」を低リスクに検証し、当たったテーマを長尺化していく方が筋がいい。

## 決定（提案）

### D-1. Phase 制で運用する

| Phase | 期間 | Shorts | 長尺 | 目的 |
| --- | --- | --- | --- | --- |
| **Phase 1** | 公開〜3ヶ月 | **週4-6本**（主軸） | **0-1本/月**（実験） | フォロワー1,000人到達 + Shorts フォーマット確立 |
| **Phase 2** | 4-6ヶ月 | 週3-4本 | **月2本** | 長尺の視聴維持率・登録者転換率を測る |
| **Phase 3** | 7-12ヶ月 | 週2-3本 | **月3-4本** | 長尺主軸に再シフト（条件達成時） or Shorts継続（未達時） |

Phase 2 移行条件は §D-4 に明記。

### D-2. Shorts フォーマット仕様（channel.yml 改訂提案）

> ⚠️ **決裁により上書き**（2026-06-09）: `duration` は **60秒固定** に変更。下表「45秒推奨」は起案時案。詳細は §決裁結果参照。


| 項目 | 値 | 根拠 |
| --- | --- | --- |
| `duration` | **45秒**（標準）／ 30-60秒の範囲で散らす | 短すぎると展開が薄く、60秒ちょうど固定は複製コンテンツ判定リスク。**45秒推奨**は「フック2.5秒 + 展開35秒 + 締め7.5秒」の収まりが良いため |
| `aspect_ratio` | **9:16**（1080×1920） | YouTube Shorts 標準。Magnific素材も縦クロップ前提で振り分け |
| `fps` | 30fps | Shorts 標準。Seedance生成は 24fps 出力もあるため、編集時に統一 |
| `resolution` | 1080×1920（FHD相当） | 4K は不要（容量・編集負荷に対してリターン薄） |
| `structure_template` | `hook` → `body` → `closer` の3パート | 7パートを圧縮（§D-3） |
| 音声 speed | 1.0 固定（変更なし） | fish audio リサンプリング劣化回避ルール継続 |
| ナレーター | こはく（変更なし） | 人格・声紋・自虐境界すべて維持 |

### D-3. 3パート構成テンプレ（45秒尺）

> ⚠️ **決裁により上書き**（2026-06-09）: 標準尺は **60秒** に変更。下表は起案時の45秒設計のため、`_pm_shorts_format_guide.md` で60秒版を再設計する（yutaka反映タスク）。


| パート | 尺 | 内容 | 規範 |
| --- | --- | --- | --- |
| **hook**（フック） | 0:00-0:02.5 | 1問1ビジュアル。「これって何のためにあるか知ってます？」型の純粋問いかけ + Magnific/Seedance の即訴求映像 | 規範③問いかけ |
| **body**（展開） | 0:02.5-0:37.5 | 雑学1ネタを「通説 → 新研究 → 解釈」の3段で。学名・出典は**字幕で**さらっと | 規範①一次情報主義 / ②さらっと引用 / ⑤中卒レベル |
| **closer**（締め） | 0:37.5-0:45 | ループ誘発の余韻（最後の1秒で冒頭フックに戻れる作り） + 「もっと詳しい話は長尺で」型CTA（長尺がある時のみ） | 規範④MECE（要約圧縮） |

**重要**: 自虐セリフは Shorts には**原則1回まで・なしも許容**。45秒尺で自虐2回はテンポを殺すため、ナレーター人格設定書 §2-3 の「あるかないか」境界をそのまま縦軸で適用。

### D-4. Phase 2（長尺試験）移行条件

以下を**全て満たす**こと:

1. **チャンネル登録者 1,000人**（YouTube収益化基準の片輪も兼ねる）
2. **Shorts 平均視聴維持率 ≥ 60%**（45秒尺のアルゴ評価ライン）
3. **Shorts ループ率 ≥ 20%**（1.2回以上の再生 ≒ 完走後ループされる）
4. **直近1ヶ月の Shorts 投稿数 ≥ 16本**（運用が型になっている証拠）
5. **EP01-N の中で「長尺化したら伸びそうなテーマ」が3本以上特定済み**（PM判断）

→ 未達の場合は Phase 1 を延長 or 戦略再評価（場合により別ADR起票）。

### D-6. KPI 設計（Shorts主軸）

**ノーススター（再定義）**:
- **Phase 1**: フォロワー獲得速度（週次の登録者増加数）
- **Phase 2 以降**: 長尺視聴維持率 + Shorts→長尺の転換率（複合）

**Shorts 個別KPI**:

| KPI | Phase 1 閾値 | 重要度 |
| --- | --- | --- |
| 平均視聴維持率 | ≥ 60% | ★★★ |
| ループ率 | ≥ 20%（再生回数/視聴回数 ≥ 1.2） | ★★★ |
| フォロワー転換率 | ≥ 0.5%（インプレッションあたり登録） | ★★ |
| 完了率（45秒最後まで） | ≥ 50% | ★★ |
| いいね率 | ≥ 5% | ★ |
| コメント率 | ≥ 0.3% | ★ |

**月次KPI**:
- 投稿本数: 16本以上（週4本×4週）
- 月間総再生回数: Phase 1 で 100万回（フォロワー1,000人逆算の目安・推測）
- チャンネル登録者: Phase 1 終了時 1,000人

**長尺 KPI（実験期）**:
- 既存 `04_kpi.md` の動画単位KPI を継続適用（CTR ≥ 4% / 維持率 ≥ 50% / 平均視聴時間 ≥ 6分）
- ただし本数が少ないため、月次集計より個別評価。長尺2本以上で類似テーマが伸びれば Phase 2 移行検討。

**Shorts→長尺 転換率（仮目標）**:
- 「Shorts視聴者のうち、長尺もクリックする率」を `Shorts視聴者の長尺平均CTR` で測る
- Phase 2 初期は ≥ 3% を仮閾値（推測。実測データで調整）

### D-7. EP01 計画の扱い

> ⚠️ **決裁により上書き**（2026-06-09）: 案A（3本Shorts分解）は **却下**。決裁採択は **案D（v1.1詳細設計はPhase 2に温存、Phase 1のShortsは別テーマで先行、Shortsで伸びたら長尺化）**。理由は「同一恐竜テーマでのShorts連投はユーザーが飽きる」なーたん明示ルール。詳細は §決裁結果参照。

**推奨**: **EP01（トリケラ求愛）は Shorts に圧縮翻案 + 長尺は保留**。

**論拠**:
- EP01 はすでに Shorts 化に適した「1ネタ完結 × ビジュアル即訴求 × 雑学性」の要件を満たす。圧縮翻案コストは新規Shorts起こしより低い。
- 長尺第1弾としての保留も妥当だが、Phase 2 移行条件を満たすまで長尺は「実験」位置づけ。EP01 を長尺の試金石として早期投入するか、Phase 2 で改めて投入するかは温度感の問題。
- **筋がいいのは「Shorts 3本に分解 + 長尺フル版は Phase 2 で公開」のハイブリッド**:
  - Shorts ①「トリケラのフリル、なんのためにあるか知ってます？」（求愛説フック）
  - Shorts ②「実は戦った傷跡が見つかってます」（Farke 2009 紹介）
  - Shorts ③「種ごとに形が全然違うってことは？」（種認識説への展開）
  - 長尺: 上記3本を統合した9:30版を Phase 2 で公開（Shorts→長尺の動線設計の実証実験）

**代替案**:
- 案B: EP01 を長尺で Phase 1 公開（実験本数1本目として）。Shorts は別テーマで先行
- 案C: EP01 自体を Shorts 1本に圧縮（最も低コストだが、せっかくの v1.1 詳細設計の活用度が下がる）

→ 推奨は **案A（3本Shorts + Phase 2長尺）**。なーたん決裁項目。

## トレードオフ

**得**:
- フォロワー獲得初速の向上（コールドスタート問題の緩和）
- 単発失敗のリスク低下（Shorts1本のコスト < 長尺1本のコスト）
- データ駆動の長尺テーマ選定（Shortsで当たったテーマを長尺化）
- 既存資産の流用率が高い（パイプライン・ライブラリ・人格・トーン）
- Shorts の高頻度投稿で「ナレーター人格こはく」の認知形成が早まる

**失**:
- 長尺収益化の到達が遅れる（広告収益の単価×総再生時間が伸びにくい構造）
- 編集ワークフローが二系統並走になる（横型 + 縦型）
- 素材ライブラリ枯渇リスク増（週4-6本ペースは素材消費が早い。4EP cooldown ルールは Shorts 換算で1ヶ月分しかカバーしない）
- 「大人雑学・おやすみ前」シーン設計と Shorts のアルゴ最適化（短く煽る方向）の緊張関係(*)
- BAN リスクの量的増加（投稿本数が多い分、リスク検知も多い）

(*) Shorts は「2.5秒で離脱されない強フック」が要求されるため、「煽らない・しっとり・余韻」のチャンネル人格と本質的に矛盾しうる。**この矛盾の許容範囲をどう設計するかが本戦略の最重要論点**（§8 ヒアリング項目で扱う）。

## なーたん決裁項目

1. **本戦略転換そのものの可否**: Shorts 主軸への組み替えを承認するか
2. **Phase 1 期間**: 3ヶ月で妥当か（短すぎ / 長すぎ）
3. **Shorts 標準尺**: 45秒推奨で良いか（30秒 or 60秒の方が良い理由があるか）
4. **EP01 の扱い**: 推奨案A（3本Shorts + Phase 2長尺）/ 案B（長尺Phase 1） / 案C（Shorts 1本に圧縮）のどれか
5. **長尺の月本数**: Phase 1 で「0-1本/月」「2本/月」「全くなし」のどれか
6. **Shorts と長尺のチャンネル分離**: 同一チャンネル運用 / 別チャンネル化（後者はサブチャンネル開設）のどちらか(*)
7. **既存EP01 v1.1 詳細設計の扱い**: Shorts翻案ガイドの起点とするか、長尺案として温存するか

(*) **PM見立て**: 同一チャンネルで運用するのが筋。なーたん「全く同じで」意向と整合 + フォロワーがShortsから長尺へ自然に流れる動線を一本化できる。別チャンネル化は管理コスト×ブランド分断のデメリットが大きい。

### 追加された運用ルール（なーたん明示）

**A. 同一恐竜・同一テーマでのShorts連投禁止**
- 1テーマ=1Shorts。複数の切り口があるテーマでもShorts化は1本のみ
- 理由: ユーザーが飽きる（アルゴ供給で同一テーマ連続表示時の離脱リスク）
- 影響: `material_reuse_policy.yml` の cooldown を「素材重複」だけでなく「テーマ重複」も対象に拡張する必要あり
- 影響: 月16本Shorts想定なら、月16の異なる恐竜・異なるテーマを起こす（manamiのリサーチ負荷増）

**B. Shorts冒頭フックは「知識欲を掻き立てるワード」**
- 採用: 「これって何のため？」「実は〜だった、知ってますか？」型の純粋問いかけ
- 不採用: 「衝撃」「ヤバい」「驚愕」「禁断」等の煽り型・ショック型
- 理由: Shorts運用への切り替えに伴う「カジュアルダウン」は許容範囲だが、煽り路線まで踏み込むとチャンネル人格（しっとり・大人雑学・おやすみ前）が壊れる
- サムネ設計思想（純粋問いかけ型・答えを匂わせない）と同じ思想で動画フックも設計

**C. 「しっとり人格 vs Shortsフック」矛盾の許容範囲**
- なーたん判断: 「Shorts運用に切り替えた時点で、ある程度のカジュアルダウンは想定内」
- 矛盾は本質的ではなく、フック設計を「煽る」ではなく「知識欲」で押し切れば回避可能と判断
