## 1. テロップの種類分け（A〜D・チャンネル全話固定）

| 種類 | 名称 | 役割 | 使用頻度 |
| --- | --- | --- | --- |
| **A** | **字幕テロップ** | ナレーション全文を表示。聴覚障害対応・無音視聴対応・電車視聴対応 | **全編常時**（音声と同期） |
| **B** | **強調テロップ** | 重要キーワード・数字・固有名詞を大きく短時間だけ出す | 1分あたり2-3回目安 |
| **C** | **引用テロップ** | 学術引用（著者・年・誌名）を画面隅に控えめに | 引用さらっと②規範ごと（EP01で8件想定） |
| **D** | **キャラ吹き出しテロップ** | こはくの自虐セリフ・問いかけ時の演出強化 | 1本2-3回（自虐2回 + 問いかけ核1回） |

### 1-1. A. 字幕テロップ（base layer）

- **使用タイミング**: ナレーション開始と同時に表示、終了と同時に消す。**全編常時表示が原則**。
- **表示尺**: 1テロップ = 1文 or 1意味区切り。読み上げ時間と完全同期（fish audio の音素タイミングに依存）。
- **フェード**: なし（カット切り替え・即時表示）。フェードは可読性を下げるため不採用。
- **同時表示**: B・C・Dと併存OK。ただし**B・Dとの併存時はAを画面下端の控えめ位置に下げる**（後述デザイン §2-4）。
- **読み上げ未完了で次テロップに切り替えない**: 「元気な女性」speed=1.0 で読み終わるタイミングをAdobe Premiere の波形で確認、字幕末尾を**100msec 残してから次に切り替え**。

### 1-2. B. 強調テロップ（spike layer）

- **使用タイミング**: 以下4種に限定。
  1. **重要キーワード**: 「フリル」「ディスプレイ説」「性淘汰」「マッチングアプリ」（核ギャグ語彙）
  2. **具体数字**: 「6600万年前」「全長9m」「頭骨2m」「傷の頻度10倍」
  3. **固有名詞・学名初出**: 「*Triceratops*」「スティラコサウルス」「カスモサウルス」
  4. **問いかけ核**: 「これって何のためにある?」「同じ種同士で戦うって、変ですよね?」
- **表示尺**: **1.5〜2.5秒**。短く出して引っ込める（VAIENCEの「数字でドンと一発」型に学習）。
- **フェード**: イン 0.15秒（スッと出す）／ アウト 0.20秒（軽く引く）。完全瞬間表示は刺激が強すぎる。
- **同時表示**: Aと併存OK（Aは下端・Bは中央〜上寄り）。CやDとは併存しない。
- **NG**: 1秒に2回以上の連発（点滅扱いになりYouTube側でフラグ立つリスク）。

### 1-3. C. 引用テロップ（credibility layer）

- **使用タイミング**: ライティング規範②「さらっと引用」とリンク。manami v1.1 §3 引用元リスト（8件）の各論文がナレーションで言及される瞬間に同期。
- **表示位置**: **画面右下隅**固定。可読サイズだが視線を奪わない大きさ。
- **表示尺**: ナレーションでの言及開始 → 終了 + 1.0秒。約3-5秒滞在。
- **フェード**: イン 0.30秒 / アウト 0.50秒（やや長め・落ち着き演出）。
- **同時表示**: Aと併存OK（Aは画面下端中央・Cは右下隅で干渉しない位置）。BやDとは原則同時に出さない。
- **フォーマット**: 「**Padian & Horner (2011)**」「**Farke et al. (2009)**」など著者+年で統一。誌名・DOIは概要欄に逃がす。

### 1-4. D. キャラ吹き出しテロップ（personality layer）

- **使用タイミング**: 以下3種に限定。
  1. **自虐セリフ核**（Part 6 締め自虐）: 「私のマッチングアプリに"いいね"が来ないのは、フリルがないせいかもしれないですね」 → 一瞬大きく見せる
  2. **核ギャグ**（Part 4 マッチングアプリ比喩）: 「マッチングアプリでプロフィール写真を盛ってた可能性が高いんです」 → 文章まるごと吹き出し化
  3. **問いかけ核**（Part 6）: 「今日の話、皆さんの何かと重なる部分ありましたか?」 → 視聴者を見る向きの吹き出し
- **表示尺**: 2.5〜4.0秒（読みやすさ優先・自虐は間を取る）。
- **フェード**: イン 0.20秒（少しコミカルに）／ アウト 0.30秒。
- **同時表示**: Dが出ているときはAを一時的に画面外に逃がす（または背景に薄く）。BCとは併存しない（情報過多になる）。
- **吹き出しの形**: 角丸長方形＋しっぽ（左下から右上に向けて）。**色は §2-2 のチャンネルパレット深緑系**。可愛さは形でなく**配色のくすみ感**で出す。

### 1-5. 同時表示マトリクス（即参照用）

| 組み合わせ | 可否 | 注意 |
| --- | --- | --- |
| A + B | OK | A下端／B中央〜上寄り |
| A + C | OK | A下端中央／C右下隅 |
| A + D | △ | Dが出る間はAを薄く or 一時非表示 |
| B + C | ✕ | 視線が散る |
| B + D | ✕ | 演出過多 |
| C + D | ✕ | トーン崩壊（学術と砕けの併置） |
| A + B + C | ✕ | 3層は禁止 |
| 単独 | OK | どれも単独表示OK |

### 2-4. 配置（セーフエリア基準）

YouTube セーフエリア = 上下5%カット想定。

| テロップ種 | 縦位置 | 横位置 | 補足 |
| --- | --- | --- | --- |
| **A 字幕** | 画面下から **15%** の位置に上端 | 中央寄せ | 下端ぎりぎりはYouTube UIで隠れるリスク |
| **B 強調キーワード** | 画面中央〜やや上（センター上40%） | 中央寄せ | 視線誘導の中心 |
| **B 強調数字** | 画面中央 | 中央寄せ | インパクト最大化 |
| **C 引用** | 画面下から **5%** 位置 | **右寄せ**（右端から3%内側） | 画面隅で視線奪わない |
| **D 吹き出し** | 画面右側（こはくが右側にいる想定） | 右寄せ（右端から5%内側） | 吹き出しのしっぽは左下向き |

**字幕とサムネキャッチの干渉回避**: hina のサムネで「これって何のためにある?」が中央配置の場合、本編開始3秒間は字幕Aを下端配置のみとし、中央クロスを避ける。

### 2-5. 縁取り・影（視認性確保）

- **縁取り**: 全テロップに **2px 黒縁**（`#1A1A1A`）を基本付与。Seedance映像は色味が暗めなのでオフホワイト文字＋黒縁で確実に浮く。
- **ドロップシャドウ**: 全テロップに **オフセット 2px / ブラー 4px / 透明度60%** で軽い影。立体感より「文字を背景から剥がす」目的。
- **二重縁取り**は使わない（過剰演出・煽りトーンに転ぶ）。

## 3. 読みやすさ基準（manami・PM共有）

### 3-1. 読書速度の前提

- 平均読書速度: **400-500文字/分 = 毎秒 7-8文字**
- 「元気な女性」speed=1.0 のナレーション速度 ≒ **毎秒 4-5文字**（読み上げベース・speed=1.0 想定範囲内のため数値変更なし）
- → **字幕は読み上げ速度に同期させれば自然に読める**。読み上げより早く字幕を切り替えない。

### 3-2. 1テロップの最大字数

- **A 字幕**: **1行20字 × 最大2行 = 40字**。これを超える文は意味区切りで分割。
- **B 強調**: 8字×1行（キーワード）／6字×1行（数字）。
- **D 吹き出し**: 16字×2行 = 32字。

### 3-3. 改行のタイミング（A字幕）

優先順位:
1. **句読点後**（「、」「。」の後）
2. **意味の区切り**（主語+述語の境界、目的語の前など）
3. **20字制限**（句読点・意味区切りがない場合の機械的改行）

**NG改行**:
- 助詞の前で改行（「フリルは / 」のような切り方）
- 漢字熟語の中で改行（「ディス / プレイ説」など）
- 数字と単位の分離（「6600 / 万年前」など）

### 3-4. 表示時間の最低保証

- 1テロップの表示時間 = **文字数 × 0.25秒** を最低ライン
- 例: 20字 → 5.0秒、10字 → 2.5秒
- 「元気な女性」speed=1.0 の読み上げ時間が上記より長い場合は読み上げ優先（字幕が先に消えない）

## 6. テロップ⇔BGM 連携ルール（重要・相互参照）

詳細は `_bgm_design_guide_2026-06-04.md` §3 に同期記載。junki視点で連携を3点だけ明示:

1. **B強調テロップ表示時にBGMは"通常維持"**: 一瞬上げない・下げない。テロップ側の視覚インパクトで足りる。BGMを動かすと耳が忙しくなる。
2. **D吹き出し（自虐セリフ）表示時にBGMは"少し下げる"**: 自虐セリフは「間」が命。BGMを-3dB下げてセリフを浮かせる。Part 6 締め自虐で実装。
3. **AI開示テロップ表示時（0:00-0:05）はBGMフェードイン直前**: BGMは0:05から立ち上げ、AI開示の間は無音 or 環境音のみ。
