## 一言で言うと

**子供向け図鑑の枠を超えた、大人のための古代生物の「ふしぎ」をじっくり語るチャンネル。**

- 「最強」「衝撃」で煽らない。「ふしぎ」「意外」「もっと知りたい」で引く。
- 雑学系の親しみと、落ち着いた語り口の両立。
- 学術精度は譲らない（雑学化≠精度低下）。

## なぜ作るのか（Why）

### 市場機会

- **国内の恐竜・古生物系YouTubeは「子供向け」か「キャラ立ちエンタメ系・最強生物トリビア系」が大半**。「大人向けの落ち着いた雑学系」というポジションは現状薄い。
- 一方で、ナゾロジー系・ふしぎ系の雑学YouTubeは大人視聴者を集めているが、**古代生物テーマでこの路線を深く掘った専門チャンネルは限定的**。ここに参入余地がある。
- 海外（特に英語圏）には BBC Earth / PBS Eons 等の良質チャンネルがあるが、トーンは学術寄り・ドキュメンタリー寄り。**「大人向け雑学」というアングルでの英語版は競合が薄い**可能性が高く、英語AI音声で横展開すれば海外CPM 2-4倍の収益性も狙える。
- 古生物学は新発見論文が定期的に出るためネタが継続的に供給される（年あたり数百本ペースで新種記載・既存種の再解釈が出る）。

### 自分たちが勝てる理由

- **なーたんの情熱領域**: 長期継続性が担保される。faceless運用の最大の弱点（モチベ枯渇）を補える。
- **Seedance 2.0 で恐竜映像生成が可能**（要品質検証）。実写素材が手に入らないジャンルこそAI映像の価値が出る。
- **最初から海外展開を見据えた言語非依存設計**が可能。テロップ・図解・サムネレイアウトを最初から英語版差し替え可能で作る。
- **「大人の雑学系」というポジショニングが現状空いている**。学術寄り（BBC Earth系）と煽り系（最強生物系）の中間レーンで、ナゾロジー的な親しみと古生物学の知的精度を両立させる枠。

## 何を届けるのか（What）

### 主コンテンツ

- 主要恐竜（ティラノ・トリケラ・ヴェロキラプトル・スピノ・プテラノドン等）の**意外な生態**を最新研究と組み合わせて解説
- 「○○は実は△△だった」「○○の常識を覆した新発見」型の雑学
- 子供向け図鑑では語られない**大人向けの細部**（顔の復元・羽毛・運動様式・繁殖行動・群れ社会・絶滅プロセス）

### サブコンテンツ

- 隣接ジャンル（絶滅哺乳類・深海古生物・氷河期生物）への展開
- 化石産地・博物館訪問記（後期フェーズ）
- 概念解説（「翼竜は鳥ではない」「恐竜の色はどこまで分かっているか」等）

## どう作るのか（How / 非属人性）

### 動画フォーマット

- **AI音声ナレーション**（落ち着いた語り口、煽らない速度）
- **Seedance生成の恐竜映像**（学術整合性チェック後、破綻カットは短く / 図解差し替えの3層運用）
- **学術図解・復元画・化石写真**（パブリックドメイン優先、論文図表は出典明記で引用範囲）
- **テロップ**（学名はラテン語表記、年代はMa併記、英語版差し替え前提のレイアウト）

### 制作パイプライン

投資chと同じ4人体制 + PM:
1. **PM**（`dinosaur-pm`）: ネタ選定・台本レビュー・素材判定・KPI監視
2. **manami**: リサーチ・台本
3. **junki**: 音声合成・編集
4. **nishi**: 映像生成
5. **hina**: サムネ・タイトル

### 想定制作工数 / 本

1本あたり 25-35時間目安。映像生成コストが投資chより大きい（恐竜映像は精度要求が高いため再生成が発生しやすい）。

### 尺

10-15分（じっくり見せる設計、雑学の余韻を出すための尺）

## トーン（ADR-006で再定義）

| 項目 | 設定 |
| --- | --- |
| トーン分類 | **大人の雑学系**（学術寄りではない／煽り系・最強生物トリビア系でもない／その中間） |
| 参照系 | 雑学系の親しみ + 落ち着いた語り口。BBC Earth系の格調は捨てる |
| 余韻設計 | **「もっと知りたい」と思わせる余韻**を毎本のクロージング設計に組み込む。次回予告で関連動画への自然な接続を作る |
| 解禁語彙 | 「ふしぎ」「不思議」「雑学」「意外」「身近な」「もっと知りたい」「ちょっと」「世界」 |
| NG語彙 | 「最強」「衝撃」「ヤバい」「すごい」「サイコパス」「闇」「禁断」等の煽り系 |
| 子供向けとの切り分け | 「大人向け」ポジショニングは保持。雑学化しても子供向けYouTubeとは別物。子供向けの「みんな知ってる○○くん」型ノリは混入させない |

### 学術精度の扱い（雑学化との両立）

トーンが「大人の雑学系」になっても、**学術的正確性の運用ルールは緩めない**。

- 推測・仮説は「〜と考えられている」「〜という説がある」と明示。断定しない。
- 最上級表現（「最強」「最大」「最古」）には限定詞をつける（「現在知られている中で最大級の」等）。
- 一次情報（査読論文・学会発表・専門書籍）優先。Wikipedia・キュレーションサイトは出発点に留め、出典まで降りる。
- 将来的な監修者契約の検討は継続（古生物学博士課程在籍者 or 学芸員クラスを月1-2回の論文チェッカーとして契約検討、月2-5万円規模を想定）。

**「雑学化＝学術精度を下げる」ではない**ことをチーム共有の前提とする。雑学化したのは**語彙・トーン・親しみ感**であって、**ファクトの精度ではない**。

## 差別化ポイント

### 競合マップ

| ジャンル | 代表 | トーン | 当チャンネルの位置 |
| --- | --- | --- | --- |
| 子供向け恐竜YouTube | 国内多数 | 派手・煽り・「最強」型 | **明確に外す**（大人向けポジション） |
| 学術寄り英語ドキュメンタリー | BBC Earth / PBS Eons / Stated Clearly | 渋い・荘厳・教養的 | **格調は採らない**（雑学系の親しみで差別化） |
| ナゾロジー系雑学YouTube | ナゾロジー、ふしぎ系チャンネル | 雑学・親しみ・「えっそうなの」型 | **トーンは近いが、古代生物特化で深掘り** |
| 最強生物トリビア系 | 国内複数 | 煽り・「ヤバい」型 | **明確に外す**（学術精度を譲らない） |

### 当チャンネルのエッジ

1. **「大人の雑学系 × 古代生物特化」というポジションの空き**を取る
2. **学術精度を譲らない雑学**: ナゾロジー系より一次情報まで降りる
3. **AI生成映像 + 図解の3層運用**で、実写では撮れない恐竜生態シーンを再現
4. **「ふしぎな世界」というブランディング**でノスタルジー × 大人の知的好奇心を両方掴む
5. **日本語版 → 英語版の流れで海外CPMも取りに行く**（長期戦略）

## 収益化シナリオ

### 短期（〜本格運用6ヶ月）

- 期待しない構造。情熱領域 × 長期資産として位置づけ。
- 投資チャンネル（channel_01_invest_youth）の収益でこちらを支える形（ADR-003）。

### 中期（本格運用6ヶ月〜12ヶ月）

- メイン: YouTube広告（学術ジャンルはCPM中程度）
- 書籍アフィリ: 古生物書籍は意外と動く市場（恐竜図鑑・学術新書・ナショジオ別冊等）。概要欄常設で月1-3万円射程
- メンバーシップ: 詳細解説・論文要約・参考文献PDF等で月数千〜数万円

### 長期（本格運用12ヶ月〜）

- 英語版立ち上げ（2026-12〜2027-03 の間で判断、海外視聴比率20%超えがトリガー）
- 英語版CPMは日本語版の2-4倍を想定、合算で月20-50万円射程
- 博物館コラボ・書籍化等の派生収益機会

### 想定単価・規模

- 日本語版だけだと月10万円届けば上出来
- 英語版が回り出せば日本語版の2-4倍CPMで上振れ余地大

## リスク

| カテゴリ | 内容 | 対処 |
| --- | --- | --- |
| ポリシー | AI生成映像で「実在の動物・場所」を再現する場合の開示要件（恐竜は実在しないため比較的軽い） | 動画冒頭または概要欄でAI開示を統一運用 |
| 著作権 | 化石写真・学術図版の利用許諾 | パブリックドメイン or CC素材中心。論文の図表は出典明記で引用範囲 |
| 飽き / 持続性 | 雑学路線に振り直したことで競合（ナゾロジー系・トリビア系）が増える領域に踏み込む。再生数稼ぎに走って空中分解するリスク | NG語彙ガード（「最強」「衝撃」等）を恐竜PMが番人として守る。学術精度ルールは絶対緩めない |
| 品質リスク | Seedanceの恐竜映像クオリティが期待値に届かない可能性 | nishiの先行検証で見極め。許容率70%が本格運用GO条件の一つ |
| トーン迷子 | 「大人の雑学系」が抽象的で、現場のmanami / nishi / hina が判断に迷う | `_pm_quality_checklist.md` で各メンバーごとの観点を明文化（2026-06-02 起草済） |
| 子供層の誤クリック | 「ふしぎな世界」が子供向けにも見えてしまう可能性 | サムネトーン・サブコピーで大人向けポジションを明示。半年運用後に再評価（ADR-006将来見直しトリガー） |
| ブランディング転換コスト | 3年後に「もっと渋い路線に振りたい」となった場合の再構築コスト | hina v1 の渋路線案（B-5 古生物図譜 等）は資産として保存。将来のリブランド選択肢として残す |
