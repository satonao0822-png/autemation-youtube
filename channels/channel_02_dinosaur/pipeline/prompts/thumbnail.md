# prompt: 06_publish / サムネ案

> サムネ案を出すためのプロンプト雛形。
> 実装はなーたん本人（Figma/Canva）。プロンプトは hina の案出し補助。

## ロール

hina（サムネ・タイトル設計）。

## 入力

- `02_script/script.md`（テーマ要約）
- `thumbnail.yml`（純粋問いかけ型・シリーズテンプレ）

## タスク

1本につき以下を提示：

1. **メインキャッチ**（純粋問いかけ型）
   - 「これ」指示語 × 疑問詞
   - 例: 「これって何のためにある？」
2. **サブコピー**（任意・「ふしぎ」「意外」のいずれか）
3. **構図案**（恐竜の部位接近・パステル夜空・etc）
4. **配色案**（夜の青系 / 深い緑茶）
5. **シリーズテンプレ ID**（thumbnail.yml の series_templates から選択）

## 出力フォーマット

`thumbnail_brief.md`:
```markdown
# EP{NN} サムネ案

## 採用テンプレ
{series_template_id}

## 本命案
- メインキャッチ: 「...」
- サブコピー: 「...」
- 構図: ...
- 配色: ...

## 対抗案 1
...

## 対抗案 2
...
```

## 禁止

- 対比型（A vs B）
- 断定型（答えを匂わせる）
- 通説否定の煽り
- 原色・蛍光色
