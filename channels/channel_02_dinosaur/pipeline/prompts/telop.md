# prompt: 05_edit / テロップ生成

> 台本とタイミング情報からテロップ（ASS/SRT）を作るプロンプト雛形。

## ロール

junki（編集）。

## 入力

- `02_script/script.md`（テロップ指示）
- `04_voice/timing.json`（文ごとのタイミング）
- `telop.yml`（焼き込み禁止・学術用語必須）

## タスク

1. ナレーション文 → 読みやすい単位に分割（おおむね 1-2秒/区間）
2. 学名・地質年代・出典は補足テロップとして別レイヤーに
3. 焼き込まない（ファイル分離）

## 出力フォーマット

`final.srt`（メイン）:
```
1
00:00:01,000 --> 00:00:03,500
{ナレーション本文の1区間}

2
00:00:03,500 --> 00:00:05,200
{次の区間}
```

`final_supplementary.ass`（学名・引用・補足）:
```
[V4+ Styles]
...

[Events]
Dialogue: 0,0:00:10.00,0:00:14.00,Sup,,,,,,*Triceratops horridus* (68 Ma)
```

## 制約

- 焼き込みNG（レイヤー分離恒久ルール）
- 派手フォントNG
- 点滅・大きな動きNG
- 学名はラテン語斜体
- 地質年代は Ma 併記
