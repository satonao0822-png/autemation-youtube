# prompt: 06_publish / メタデータ生成

> タイトル・概要欄・タグを作るプロンプト雛形。

## ロール

hina + 恐竜PM。

## 入力

- `02_script/script.md`（本編要約）
- `01_research/sources.md`（引用文献）
- `publish.yml`（テンプレ・タグベース・開示文）

## タスク

以下を出力：

1. **タイトル**（28字以内目安・シリーズテンプレ「○○じゃなかったかもしれない話」型）
2. **概要欄**:
   - 1行目: シーン宣言（「おやすみ前の、大人のための古代生物雑学。」）
   - 2-3行目: AI開示
   - エピソード要約（2-4行）
   - チャプターリスト（`0:00 オープニング` 等）
   - 引用文献（和訳タイトル + 原タイトル + DOI/URL）
   - 関連動画
   - チャンネル情報
   - ハッシュタグ（`#恐竜 #古生物 #雑学` 等3つ）
3. **タグ**（最大15個。base から5 + EP固有10）

## 出力フォーマット

`meta.yml`:
```yaml
title: "..."
description: |
  おやすみ前の、大人のための古代生物雑学。
  本動画はAI音声・AI生成映像を含みます。

  {本編要約}

  ▼ チャプター
  0:00 オープニング
  ...

  ▼ 引用文献
  ...

  ▼ 関連動画
  ...

tags:
  - 恐竜
  - 古生物
  - ...
category_id: 27
default_language: ja
made_for_kids: false
```

## 必須チェック

- AI開示の文言が概要欄に存在
- 引用文献が概要欄に存在
- タイトルにNG語彙が含まれていない
