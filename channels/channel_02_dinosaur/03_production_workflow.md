## パイプライン全体図

```
（先行）Seedance 含む3ソース戦略の運用フロー設計・プロンプトテンプレ整備（nishi、API課金なし）
→ ネタ選定(恐竜PM + manami) → 構成案(manami・8-10分尺) → 台本(manami) → 恐竜PMレビュー
→ 音声合成(junki・「元気な女性」speed=1.0 固定) → 映像生成(nishi・3ソース運用)
→ 編集(junki) → サムネ案出し(hina) → サムネ実装(なーたん本人)
→ 恐竜PM最終チェック → yutaka確認 → なーたん承認 → 公開
→ 分析(恐竜PM + 各員)
```

**動画尺**: **8-10分でテーマに応じてPMが散らす**（8分ぴったり固定はNG・複製コンテンツ判定リスク回避）。詳細は `02_content_strategy.md` 動画フォーマット詳細。

## 品質チェックリスト（公開前）

### 内容

- [ ] 学術ソース（論文・大学・博物館）の出典が概要欄に明示されているか
- [ ] 推測・解釈部分は「○○とされている」「研究者の間では○○の見方もある」など中立表現か
- [ ] 子供向け迎合表現（「最強」「ヤバい」「衝撃」等のNG語彙）が混入していないか
- [ ] 最上級表現に限定詞がついているか（「現在知られている中で最大級の」等）
- [ ] 学名はラテン語表記（斜体運用）、地質年代は Ma 併記
- [ ] 「もっと知りたい余韻」がクロージング設計に組み込まれているか
- [ ] 関連動画・再生リストへの自然な接続があるか

### 技術

- [ ] AI生成恐竜映像のクオリティが視聴に耐えるか（Seedance本格運用GO条件: 許容率70%基準）
- [ ] 3ソース配分（無料ストック25% / Magnific35% / Seedance40%）が本数の範囲で実現されているか
- [ ] 破綻カットが図解・復元画・化石写真に差し替えられているか
- [ ] 動画尺が **8-10分の範囲**に収まっているか（8分ぴったり固定NG）
- [ ] BGM・効果音の著作権クリア
- [ ] 字幕の誤字脱字（学名・カタカナ表記特に注意）
- [ ] 「AI音声・AI生成映像を含む」開示が動画冒頭または概要欄にあるか

### プロジェクト構造（修正容易性のため維持）

- [ ] テロップが映像に焼き込まれず、レイヤー分離されているか
- [ ] ナレーション音声トラックがBGM・SEと独立して配置されているか
- [ ] サムネ素材が PSD/AI で編集可能な形で `assets/thumbnails/` に保存されているか

→ 上記は英語版差し替え前提の名残ではなく、**編集の修正容易性・将来の英語版再開対応・サムネ再リリース対応の3点で恒久ルールとして採用**。
