## パイプライン全体図

```
（先行）Seedance 恐竜映像品質検証(nishi) → 本格運用ADR起案（恐竜PM起案 → yutaka経由なーたん決裁）
→ ネタ選定(恐竜PM + manami) → 構成案(manami) → 台本(manami) → 恐竜PMレビュー
→ 音声合成(junki) → 映像生成(nishi) → 編集(junki)
→ サムネ・タイトル(hina) → 恐竜PM最終チェック → yutaka確認 → なーたん承認 → 公開
→ 分析(恐竜PM + 各員)
```

## 各工程の担当・所要時間・ツール（本格運用フェーズ・想定）

| 工程 | 担当 | 所要時間 | ツール / 補足 |
| --- | --- | --- | --- |

| 構成案 | manami | 2-3時間 | 学術ソースのファクトチェック前提、雑学トーンの構成テンプレに沿う |
| 台本 | manami | 6-8時間 | 一次情報優先、推測の明示、最上級限定詞。トーンは「もっと知りたい余韻」 |

| タイトル/概要欄 | hina + 恐竜PM | 1時間 | 出典・参考文献を必ず概要欄に記載。シーン宣言「おやすみ前の大人雑学」は概要欄冒頭1行で運用。タイトルはシリーズ二系列テンプレ「○○じゃなかったかもしれない話」を装飾形質再解釈テーマで適用 |

## 品質チェックリスト（公開前）

### 内容

- [ ] 学術ソース（論文・大学・博物館）の出典が概要欄に明示されているか
- [ ] 推測・解釈部分は「○○とされている」「研究者の間では○○の見方もある」など中立表現か
- [ ] 子供向け迎合表現（「最強」「ヤバい」「衝撃」等のNG語彙）が混入していないか
- [ ] 最上級表現に限定詞がついているか（「現在知られている中で最大級の」等）
- [ ] 学名はラテン語表記（斜体運用）、地質年代は Ma 併記
- [ ] 「もっと知りたい余韻」がクロージング設計に組み込まれているか
- [ ] 関連動画・再生リストへの自然な接続があるか

### 技術

- [ ] AI生成恐竜映像のクオリティが視聴に耐えるか（許容率70%基準）
- [ ] 破綻カットが図解・復元画・化石写真に差し替えられているか
- [ ] BGM・効果音の著作権クリア
- [ ] 字幕の誤字脱字（学名・カタカナ表記特に注意）
- [ ] 「AI音声・AI生成映像を含む」開示が動画冒頭または概要欄にあるか

### プロジェクト構造（修正容易性のため維持）

- [ ] テロップが映像に焼き込まれず、レイヤー分離されているか
- [ ] ナレーション音声トラックがBGM・SEと独立して配置されているか
- [ ] サムネ素材が PSD/AI で編集可能な形で `assets/thumbnails/` に保存されているか

→ 上記は英語版差し替え前提の名残ではなく、**編集の修正容易性・将来の英語版再開対応・サムネ再リリース対応の3点で恒久ルールとして採用**。
