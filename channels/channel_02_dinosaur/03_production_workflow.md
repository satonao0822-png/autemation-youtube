## パイプライン全体図

```
（先行）Seedance 恐竜映像品質検証(nishi) → 本格運用ADR起案
→ ネタ選定(yutaka/manami) → 構成案(manami) → 台本(manami) → yutakaレビュー
→ 音声合成(junki) → 映像生成(nishi) → 編集(junki)
→ サムネ・タイトル(hina) → yutaka最終チェック → なーたん承認 → 公開
→ 分析(yutaka + 各員)
```

## 品質検証フェーズ（2026-06-01〜）

| 工程 | 担当 | 内容 |
| --- | --- | --- |
| Seedance 恐竜映像生成検証 | nishi | 代表種3-5体（ティラノ、トリケラ、ヴェロキラプトル、プテラノドン等）で生成テスト |
| 検証結果まとめ | nishi | 品質・コスト・生成時間を `assets/seedance_test_log.md` に記録 |
| 本格化判断 | yutaka + なーたん | 検証結果を元に本格運用ADR起案 |

## 各工程の担当・所要時間・ツール（本格運用フェーズ・想定）

| 工程 | 担当 | 所要時間 | ツール / 補足 |
| --- | --- | --- | --- |
| ネタ選定 | yutaka + manami | 1時間/週 | 新発見論文・最新研究のウォッチ |
| 構成案 | manami | 2-3時間 | 学術ソースのファクトチェック前提 |
| 台本 | manami | 6-8時間 | 学術寄り、論文出典明記 |
| 台本レビュー | yutaka | 1時間 | 学術的誤情報・著作権チェック |
| 音声合成 | junki | 2時間 | Fish Audio 落ち着いた声質、英語版時は英語クレジット |
| 映像生成 | nishi | 8-10時間 | Seedance 2.0 Pro 恐竜映像（精度要求が高い） |
| 編集 | junki | 4-6時間 | しっとり編集、BGMはCC0オーケストラル等 |
| サムネ | hina | 2-3時間 | 言語非依存設計（英語版流用前提） |
| タイトル/概要欄 | hina + yutaka | 1時間 | 出典・参考文献を必ず概要欄に記載 |
| 分析 | yutaka中心 | 1時間 | 投資chと別の指標（視聴維持率と離脱ポイント重視） |

## 品質チェックリスト（公開前）

### 内容
- [ ] 学術ソース（論文・大学・博物館）の出典が明示されているか
- [ ] 推測・解釈部分は「○○とされている」「研究者の間では○○の見方もある」など中立表現か
- [ ] 子供向け迎合表現（「最強」「ヤバい」等）が混入していないか

### 技術
- [ ] AI生成恐竜映像のクオリティが視聴に耐えるか
- [ ] BGM・効果音の著作権クリア
- [ ] 字幕の誤字脱字（学名・カタカナ表記特に注意）
- [ ] 「AI音声・AI生成映像を含む」開示

### 海外展開準備（日本語版時点で意識）
- [ ] サムネのテロップを「最小限」にして英語版流用可能か
- [ ] 図解・グラフが言語非依存か（テキストは画像差し替え前提に分離）

## ファイル命名規則

- 台本（日本語）: `scripts/EP{NN}_{slug}.md`
- 台本（英語）: `scripts/EP{NN}_{slug}_en.md`（英語版展開時）
- サムネ: `assets/thumbnails/EP{NN}_{slug}_{ja|en}_v{N}.{png|psd}`
- 映像検証ログ: `assets/seedance_test_log.md`
- 分析メモ: `analytics/EP{NN}_{slug}_{YYYY-MM-DD}.md`
