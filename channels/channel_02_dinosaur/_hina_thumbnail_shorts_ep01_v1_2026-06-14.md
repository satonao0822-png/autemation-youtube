## 1. タイトル案 — 5本

> **採点軸**: ①純粋問いかけ／②「これ」指示語×疑問詞／③結論ワード非含有／④20字以内（Shorts視認性）／⑤クリックしたくなる強度

| # | タイトル案 | 字数 | 指示語×疑問詞 | 結論非含有 | 強度 | 備考 |
| --- | --- | --- | --- | --- | --- | --- |
| **T1（推奨）** | **トリケラトプスのこれって何のためにある?** | **20字** | ◎（「これ」×「何のため」） | ◎ | ★★★★★ | **長尺v1.1サムネキャッチを完全踏襲**。なーたん2026-06-02直接指定の正解形。Shorts第1本に最も安全 |
| T2 | トリケラトプスのこれ、何のため? | 15字 | ◎（「これ」×「何のため」） | ◎ | ★★★★☆ | T1の短縮版。視認性↑だが「にある」「だと思う」の含み余地が削れ、純粋問いかけの強度はやや低下 |
| T3 | この恐竜のこれ、何のためだと思う? | 16字 | ◎（「これ」×「何のため」） | ◎ | ★★★☆☆ | 恐竜種伏せ案。サムネで「トリケラ」と分かる画があれば成立。closerセリフ「あなたなら何のためだったと思いますか?」と韻を踏める |
| T4 | あなたなら、これ、何のためだと思う? | 17字 | ◎（「これ」×「何のため」） | ◎ | ★★★☆☆ | closer文言「あなたなら、このフリル、何のためだったと思いますか?」直結。視聴後の余韻が冒頭に効く設計だが、初見強度はT1劣後 |
| T5 | トリケラトプスのこの飾り、知ってる? | 17字 | △（指示語のみ・疑問詞「知ってる?」は弱い） | ○（「飾り」は中立語） | ★★☆☆☆ | バリエーション枠。「飾り」中立語にしたが「知ってる?」が疑問形として弱く、知識欲スコア低い |

### 推奨: **T1「トリケラトプスのこれって何のためにある?」**

**Why:**
1. なーたん 2026-06-02 直接指定で長尺EP01用に既に採用された正解形（再現性最高）
2. **「これ」×「何のためにある」がなーたん基準を100%満たす**
3. Shorts/長尺の**ブランディング統一**（同じ問いかけを2フォーマットで反復→チャンネル記憶定着）
4. 結論ワード（盾・戦う・フリル・異性）ゼロ
5. 20字でShorts縦9:16の画面上1/4に2行（10字×2行）でちょうど収まる

**サブ推奨: T3「この恐竜のこれ、何のためだと思う?」** — T1がチャンネル横断で「またこれか」と既視感が出てくる時期（5本目以降）の差し替え候補。視聴者がトリケラと自分で気づく**主体性ブースト**を狙える。

## 2. 1フレーム目（実質サムネ）デザイン構成

### 2-1. 構成原案（A案・推奨）

```
┌─────────────────────────┐
│                         │
│   トリケラトプスの   │ ← 上部1/4
│      これって       │   テキストエリア
│    何のためにある?  │   （白・縁取り赤・太字）
│                         │
├─────────────────────────┤
│                         │
│                         │
│      [トリケラ正面     │ ← 中央1/2
│       首振り中の       │   nishi Seedance①
│       キーフレーム]     │   フリル広角ショット
│                         │
│      フリル部分に       │
│      ソフト周辺減光    │
│                         │
├─────────────────────────┤
│                         │
│  （無装飾・余白）        │ ← 下部1/4
│                         │
└─────────────────────────┘
```

| 要素 | 仕様 | 根拠 |
| --- | --- | --- |
| **アスペクト比** | 9:16（1080×1920px） | Shorts縦動画規格 |
| **テキスト配置** | 画面上部1/4（y: 0-480px帯） | 親指UI領域回避・スクロール時の最初の0.3秒で読める位置 |
| **テキスト分行** | 「トリケラトプスの」「これって」「何のためにある?」3行 or 「トリケラトプスのこれって」「何のためにある?」2行 | 視認性試験：2行案を本命、3行案は予備 |
| **フォント** | 太ゴシック（Noto Sans CJK Bold相当） | ref01踏襲・小サムネ可読性 |
| **メインカラー** | 白本文 + 赤縁取り（4-5px） | テロップ3色強調マトリクスのL1ロジック準拠 |
| **アクセント** | 「これって」を赤太字・特大化 | 「これ」指示語を最強調（なーたん基準の核） |
| **中央画像** | nishi Seedance①トリケラ正面首振りカットの**0:01-0:02のキーフレーム**（フリルが画面に広角で見える瞬間） | ブリーフv3 §3 hina想定踏襲 |
| **背景演出** | 周辺減光（ビネット）・フリル輪郭にリムライト | なーたん基準「学術トーン整合の手法」 |
| **下部余白** | 無装飾 | 「コメント欄で…」CTA字幕はclose時点で出すため冒頭は無装飾でテキスト集中 |
| **彩度** | `00_concept.md` 落ち着いた色調維持。テロップ色のみ強コントラスト | ブリーフv3 §3 デザイン全体方針 |

### 2-2. B案（テキスト2行版・縮約レイアウト）

```
┌─────────────────────────┐
│  トリケラトプスのこれって │ ← 上部1/5
│   何のためにある?       │
├─────────────────────────┤
│                         │
│     [トリケラ正面       │ ← 中央3/5
│      首振りキーフレ]    │   画像エリア拡大
│                         │
├─────────────────────────┤
│   （ソフト周辺減光）     │ ← 下部1/5
└─────────────────────────┘
```

- A案より**画像比率↑**（中央3/5）、テキストは2行に詰める
- 画像の主役感が強く、トリケラを見せる強度はA案より高い
- ただし**テキスト視認性はA案がやや勝る**（1行あたりの文字数が多くなる）

### 2-3. 採用優先順

1. **A案（推奨）**: テキスト3行・上部1/4配置。**「これって」の特大強調が可能** → なーたん基準の核「指示語強調」が最大化
2. **B案**: 画像主役・テキスト2行。トリケラ視認性が高くスクロール停止率は理論上高い可能性。**A/Bテスト後半の差し替え候補**

→ **初回投下はA案**。公開後1週間のCTRデータで必要に応じB案差し替え（junkiとA/Bテスト設定で連携）。

- junkiは hina 納品データを動画冒頭0.5秒に静止フレーム挿入（タイトル視認時間確保）
