## 1. 三行サマリ（結論先出し）

- **Seedance（シーダンス）= ByteDance（TikTok運営元）が出している動画生成AI**。文章や画像から5〜10秒の動画クリップを作る。1080p対応。現在は **1.0 Pro** と **2.0** が併存（2.0は2026年2月リリース）。
- **料金は従量制（使った分だけ）**。1080p / 5秒で **$0.62〜$0.75（90〜110円）/本**。月4本（EP4本）×Seedanceカット比率45%で **月額の純粋な生成費は $50〜$80（7,000〜12,000円）程度** の見込み。失敗・再生成込みで **月 $100〜$150（15,000〜22,000円）が現実値**。
- **APIは公開されている**ので、原理上は nishi エージェントから自動生成リクエスト可能。ただし **学術精度の判定（指の本数・歯列・羽毛の有無等）は人間（nishi）の目が必要**。**「Claudeに全自動投げっぱなし」は推奨しない**。半自動（プロンプト設計と判定は人間、生成リクエスト自体は自動化）が現実解。

## 2. Seedanceとは（ゼロからの説明）

### 2-1. 誰が作っているか

- **ByteDance（バイトダンス）= TikTokの運営元**。中国本社の大手テック企業。
- Seedanceは ByteDance の AI研究部門 **「ByteDance Seed」** が開発したモデル。
- 同じByteDance内の AIアシスタント「Doubao（豆包・ドウバオ）」エコシステムの一部。中国でDoubaoは週間1.5億ユーザー規模のチャットAI。

### 2-2. 何ができるか

| 機能 | 説明 |
| --- | --- |
| テキスト→動画（Text-to-Video） | 「白亜紀の森を歩くトリケラトプス、横アングル」のような**文章のプロンプトから動画を生成** |
| 画像→動画（Image-to-Video） | **静止画を入力して、その画像を動かす**。学術復元画を入力して動かすこともできる（恐竜chでは重要） |
| 動画→動画 | Seedance 2.0で追加。既存動画の編集・変換（参考程度。我々はあまり使わない見込み） |
| 音声付き生成 | Seedance 2.0で「映像と音声を同時生成」可能。ただし我々は自前ナレーション（manami台本→junki音声合成）なので**音声機能は基本オフ運用** |

### 2-3. 出力スペック

- **解像度**: 480p / 720p / **1080p** に対応（4Kは現状非対応。Veo3が4K対応）
- **長さ**: **5秒 または 10秒**（10秒以上は1本では作れない。長いシーンは複数本繋ぐ運用）
- **フレームレート**: 30fps
- **生成時間**: 1080p 5秒の動画を **1分以内で生成**（爆速。これがSeedanceの強み）

### 2-4. 競合との立ち位置（2026年6月時点）

| モデル | 開発元 | 料金（秒単価） | 強み | 弱み |
| --- | --- | --- | --- | --- |
| **Seedance 1.0 Pro / 2.0** | ByteDance | $0.12〜0.15/秒 | **高品質×低価格のバランス最強**。生成速度が速い | API周りの英語ドキュメントがやや薄い |
| Veo 3 / 3.1 | Google | $0.15/秒〜（fastモード） | **4K対応・ネイティブ音声**。放送品質 | 価格高め |
| Sora 2 | OpenAI | **$0.75/秒** | 物理シミュレーションが最強。映画的 | **高い**。Web/Appは2026年4月終了、APIは9月まで |
| Runway Gen-4 | Runway | サブスク中心 | UIが使いやすい。クリエイター向け機能 | 単価あたりの品質は他社に劣る |
| Kling 3.0 | Kuaishou（快手） | **$0.10/秒** | **最安**。中国モデル | 品質はSeedance/Veoに次ぐレベル |

**位置づけ要約**: Seedance は **「Veo並みの品質を、Soraの1/5の価格で出す」** ポジション。Klingより少し高いが品質が一段上。**コスパで選ぶならSeedanceが現状最良**。

### 2-5. 我々がSeedanceを選んだ理由（差別化軸D-1）

`_pm_memo_ep01_longlist.md` のロングリスト評価で、各案のSeedance適性が事前評価されている。整理すると以下:

- **四足歩行・全身カットでの破綻率が低い**（トリケラ等の角竜類で実証）
- **1本$0.62という価格帯がチャンネル予算に合う**（Soraだと月額予算が5倍に膨らむ）
- **生成速度が速い（1分以内）** → 1日に大量のバリエーション試行が可能。これが「破綻したら短尺化 or 差し替え」運用と相性が良い
- **ByteDanceがTikTokで培ったショート動画の感覚** → 5〜10秒という短尺前提の設計が、我々のカット運用と噛み合う

「差別化軸D-1 = AI映像でしか作れない映像表現」を成立させる土台として、コスパと量産性の両立がSeedanceの優位点。

## 3. アカウント取得・料金体系

### 3-1. どこからアクセスするか（3ルートある）

| ルート | 概要 | 日本から使えるか | 推奨度 |
| --- | --- | --- | --- |
| **A. Volcano Engine Ark（公式・中国本土）** | ByteDance本社のクラウド。`volcengine.com` | **中国本土の携帯番号（+86）が必要** → 日本からは登録が困難 | × |
| **B. BytePlus（公式・国際版）** | ByteDance国際向け。USD決済・国際法準拠 | **メールとクレジットカードでOK**。日本から普通に登録可能 | **◎ 第一候補** |
| **C. fal.ai / Replicate（サードパーティAPI）** | 各社のAIモデルを横断的に提供するAPIプラットフォーム | **メールとクレジットカードでOK** | **○ 第二候補** |

### 3-2. アカウント取得手順（推奨ルートB: BytePlus）

1. `byteplus.com` にメール登録（個人事業主名義でOK）
2. クレジットカード登録（USD建て決済）
3. APIキー発行
4. 利用開始

中国の携帯番号は不要。日本の個人事業主・法人でそのまま使える。

### 3-3. 料金体系（従量制 = トークン課金）

**「クレジット制」というより「使った秒数 × 解像度で課金」と理解してOK**。

| プラン | 料金 | 換算 |
| --- | --- | --- |
| Seedance 1.0 Pro（テキスト→動画） | **トークン100万あたり $3.00** | 1080p 5秒動画 ≒ 30万トークン ≒ **$0.74〜$0.75/本** |
| Seedance 1.0 Pro（画像→動画） | 同上 | 同上（**約 $0.62/本** という値も。出力設定で若干変動） |
| Seedance 1.0 Lite | トークン100万あたり $1.8 | 720p 5秒 ≒ **$0.18/本**（試行用に最適） |
| Seedance 2.0（音声付き） | **約 $0.14/秒** | 5秒 ≒ **$0.70/本**、10秒 ≒ **$1.40/本** |

**「トークン」とは**: トークン = （画面の縦 × 横 × FPS × 秒数）÷ 1024 で計算される計算量の単位。実質「動画のデータ量に応じた課金」。

| --- | --- | --- | --- |
| **本番カット**（1080p×5秒） | Pro / 高品質 | **$0.62〜$0.75** | **約93〜113円** |

### 3-5. 無料枠

→ **最初のテスト3〜5本は無料枠でカバー可能**。本格運用前のプロンプト検証はこの範囲で十分。

## 4. Claude / 自動化からの利用可否（最重要論点）

### 4-1. APIは公開されているか

**Yes、公開されている**。具体的には以下:

- BytePlus: `https://ark.ap-southeast.bytepluses.com/api/v3/...`（国際版エンドポイント）
- fal.ai: `https://fal.ai/models/fal-ai/bytedance/seedance/v1/pro/...`
- Replicate: 同様にBytedance Seedanceモデルを提供

**つまり、Claude / nishiエージェントから HTTPリクエストでSeedanceに動画生成を依頼することは技術的に可能**。

### 4-2. ではClaude（nishiエージェント）に丸投げできるか？

**結論: できるが、推奨しない**。理由は以下。

| 工程 | 自動化可否 | 推奨運用 |
| --- | --- | --- |
| プロンプト設計（恐竜の種・アングル・環境指定） | 半自動可 | **nishi（人間）が画コンテに基づき設計**。テンプレ化はする |
| API経由でSeedanceに生成リクエスト送信 | **完全自動可** | nishiエージェント（Claude）が API叩いて生成キュー投入してOK |
| 生成結果のダウンロード・ファイル管理 | **完全自動可** | nishiエージェントが自動で `assets/EP{NN}/seedance_raw/` に保存 |
| **学術精度判定**（指の本数・歯列・羽毛・解剖学） | **自動化NG** | **nishi（人間）が目視判定**。Claudeでは判定不能 |
| **採用カット選定**（OK/短尺化/差し替え） | 自動化NG | nishi 判定。PMチェック §2-B の3層判定 |
| プロンプト改善・再生成判断 | 半自動 | nishi が方向性決め、Claudeがバリエーション生成 |

### 4-3. なーたんの問い「Claudeに任せて月次運用が回るのか／毎回 nishi が手動操作するのか」への回答

**答え: 「半自動運用」が正解**。具体的には:

1. **生成リクエスト送信・ダウンロード・ファイル管理 = 自動化**
   → nishiエージェント（Claude）がスクリプト経由で実行。なーたんが操作することはない。
2. **プロンプト設計・採否判定 = 人間（nishi）が責任を持つ**
   → ここを自動化すると **指3本のティラノが量産される** リスク。学術精度は妥協できない。

**運用イメージ**:
- nishi が画コンテで「シーン7: トリケラ全身カット、横アングル」を設計（30分）
- nishi がプロンプトを書いて、Claudeに「3バリエーション生成して」と指示
- Claude が API叩いて3本生成 → 5分後にダウンロード完了通知
- nishi が3本見て「v2採用、v1とv3は破綻」と判定
- 月4本ペースなら、**nishi の実労働は週10〜15時間**程度に収まる見込み（提案書§1の見積もりと整合）

### 4-4. なーたんが意識する必要があること

- **「Seedance生成自体は誰も手動でぽちぽちやらない」**（ここは自動化される）
- **「破綻判定だけは人間（nishi）が責任を持つ」**（ここは外注も自動化も不可）
- **APIキー管理・課金状況は yutaka と nishi で月次レビュー**（コスト暴走防止）

## 5. 月額試算（恐竜chの本格運用）

### 5-1. 試算前提

- **EP1本 = 10〜15分尺**（実質尺、短くなる方向）
- **EP1本あたり総カット数 = 30〜40カット**（提案書§2-3より）
- **Seedance生成カット比率 = 45〜55%**（EP01見立て）
- **1カット = 5〜10秒**（平均 7秒として試算）
- **月4本ペース**（土曜公開）
- **1カットあたり生成バリエーション = 2.5本**（1発採用率30〜40% → 平均2〜3本生成）

### 5-2. 月額試算（純粋な生成費）

| 項目 | 計算 | 数量 |
| --- | --- | --- |
| EP1本あたりSeedanceカット数 | 35カット × 50% | 17.5カット |
| EP1本あたり生成本数（バリエーション込み） | 17.5 × 2.5本 | **約44本** |
| 月4本 ×44本 | 月間生成本数 | **約175本** |
| 1本あたり平均コスト（1080p 7秒） | $0.62〜$0.75 × 7/5 | **約$0.87〜$1.05** |
| **月額生成費** | 175本 × $0.87〜$1.05 | **約 $152〜$184** |
| **月額生成費（JPY、$1=¥150）** | | **約 22,800〜27,600円** |

### 5-3. 失敗・再生成バッファ込みの現実値

- プロンプト改善試行・テンプレ作成試行 = 月+20〜30本
- 学術判定NGからの再生成 = 月+15〜20本
- **現実値: 月 $180〜$220（約 27,000〜33,000円）/ 月4本ペース**

### 5-4. 安価運用のオプション（Liteモード活用）

- **プロンプト検証段階は Lite（720p）で試す**（1本$0.18）→ 採用方向性が固まったら Pro（1080p）で本生成
- これで **月額を $120〜$150（18,000〜22,500円）まで圧縮可能**
- nishi推奨運用: **「Lite で試行 → Pro で本生成」の2段階運用**

### 5-5. EP1本あたりコスト

- Pro一発勝負: **約 $40〜$55（6,000〜8,300円）/ EP**
- Lite→Pro 2段階運用: **約 $30〜$40（4,500〜6,000円）/ EP**

→ **YouTube収益化前のチャンネル立ち上げ期でも、月3万円台の生成費で回せる**。広告収益化（月10万再生程度から）と比較して十分ペイする想定。

## 7. nishi の推奨運用方針

### 7-1. 採用構成

- **メインモデル**: Seedance 1.0 Pro（1080p / 5〜10秒 / Text-to-Video & Image-to-Video）
- **試行モデル**: Seedance 1.0 Lite（720p、プロンプト検証用）
- **APIプロバイダー**: **BytePlus（第一候補）**、fal.ai（バックアップ）
- **アクセス方法**: nishiエージェント（Claude）から API経由で生成リクエスト → 自動ダウンロード → nishi が目視判定

### 7-2. 運用ルール

1. **学術判定は人間（nishi）が責任**。Claude任せにしない。
2. **Lite→Pro の2段階運用**でコスト圧縮。
3. **月次でyutaka に課金レポート**（コスト暴走防止）。
4. **APIキーは BytePlus と fal.ai の2系統持つ**（片方が止まっても作業継続できるよう冗長化）。
5. **商用利用**: Seedance（ByteDance系）はYouTube収益化目的の商用利用OK。**AI生成であることのYouTube側開示は別途必要**（yutaka 経由で `00_concept.md` 等に反映済み）。

### 7-3. リスク対応

- **料金改定リスク**: ByteDanceは過去6か月で2.0をリリース＆価格改定。**月次で料金チェック**を nishi の作業に組み込む。
- **サービス停止リスク**: 中国系サービス特有の地政学リスクがゼロではない。Veo 3 / Klingでの代替検証を **EP05時点で予備調査** しておく（緊急乗り換え時の準備）。
- **学術精度リスク**: 提案書§4-1の「種ごとの採用率推定」を継続的に更新。Seedance のモデルバージョンが上がるたびに再評価。
