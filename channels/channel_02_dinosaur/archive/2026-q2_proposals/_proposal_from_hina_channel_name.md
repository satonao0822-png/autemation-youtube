## 設計方針メモ（hinaの考え方）

依頼書の「3軸の切り方ごと提案」を尊重しつつ、参考例（学術アーカイブ系 / 詩的・情景系 / 研究最前線系）よりも「**チャンネル名として長期運用で機能するか**」の観点で軸を切り直しました。最終的な3軸はこうです:

- **方向A: 時間軸を引き受ける系** — 「失われた時間」を扱う器であることを名前で宣言する系。BBC Earth系のしっとり詩情。
- **方向B: ノート / 書物メタファー系** — 知の蓄積、書庫、フィールドノート。学術寄り。情熱で積み上げる長期運用との相性が良い。
- **方向C: 化石 / 痕跡を主役にする系** — 「恐竜そのもの」ではなく「化石・痕跡・記録」を主役に置く。大人向けの距離感が出る。学術的誠実さも担保。

「研究最前線系」は1本2本のサブテーマとしては良いがチャンネル名としては時事性が強すぎ（3年運用で陳腐化する懸念）、そのため最前線感はサムネ/タイトル側で出す方針で、チャンネル名軸からは外しました。

日英ペアは「直訳」ではなく「**同じ世界観を日本語圏・英語圏で独立に成立させる相棒**」として組んでいます。

## 方向A: 時間軸を引き受ける系

「失われた時代」「深い時間」を器として宣言するタイプ。BBC Earth / Prehistoric Planet 的なしっとり詩情。30-50代の知的好奇心に静かに刺さる路線。

- **案A-1: 失われた地平 / Lost Horizons** — 「地平」は時間と空間を同時に内包する語。恐竜の世界=もう戻れない地平、という静かな入口。英語 Lost Horizons は複数形にすることで「中生代・古生代・新生代…幾重もの失われた地平」を含意。
- **案A-2: 深淵紀 / Deep Time** — 地質学用語 "deep time"（深い時間）を日本語側で詩的に翻訳。「紀」を据えることで地質年代との接続を匂わせる。英語の Deep Time は古生物界では準・専門用語で英語圏での通りも良い。
- **案A-3: 化石時計 / The Fossil Hours** — 化石を時計に見立てる比喩。1本の動画=失われた時間の1コマ、というシリーズ性が出る。英語側は "Hours" 複数形で時間のレイヤー感を出す。
- **案A-4: 太古便り / Letters from Deep Time** — 「太古からの便り」というメタファーで毎本届く設計を匂わせる。英語側 Letters from Deep Time は素直に詩的で英語圏でも違和感なし。やや柔らかめで親しみが出る路線。

---

## 方向B: ノート / 書物メタファー系

研究ノート、フィールドノート、書庫。学術寄り、積み上げる長期運用と相性◎。「Note」「Archive」「Field」「Journal」をベースに、仮称案（Paleo Note / 化石ノオト / 古生物アーカイブ）の世界線を本気で詰めた版。

- **案B-1: 古生物手帖 / Paleo Field Notes** — 「手帖」は日本語側で学者の私的記録の質感が出る。英語 Paleo Field Notes は古生物学者のフィールドノート＝海外古生物クラスタに刺さる王道ワード。日英でほぼ同じ距離感に着地する優秀ペア。
- **案B-2: 化石書庫 / The Fossil Archive** — 「書庫」は静謐で、量産で積んだとき棚が増えていく感覚が出る。英語 The Fossil Archive は定冠詞 The が効いて「あの書庫」という固有性を立ち上げる。
- **案B-3: 古生物覚書 / Paleo Memoranda** — 「覚書」は学術寄りで硬すぎず、毎本=1メモという積み方が綺麗。Memoranda（複数形）は英語圏ではやや堅めだが学術系・図書館系チャンネル名としては成立。少し攻めた案。
- **案B-4: 化石ノオト / Fossil Notebook** — 仮称にあった「化石ノオト」をhinaなりに正式化。カタカナ「ノオト」の古書感は捨てがたい。英語 Fossil Notebook は素直で検索性も良好。一番親しみ寄り。
- **案B-5: 古生物図譜 / The Paleo Folio** — 「図譜」は江戸〜明治の博物図譜の質感。Folio は判型由来で書物・図版集の含意。**最も学術寄り・最も渋い**。3年経っても古びない王者ポジ狙い。

---

## 方向C: 化石 / 痕跡を主役にする系

主役を「恐竜」ではなく「化石・痕跡・記録」に置く。これは大人向けポジションを名前で宣言する効果が大きい（子供向け恐竜チャンネルは100%「恐竜が主役」を名乗るため、ここをずらすだけで競合と一線を引ける）。学術的誠実さも自動的に担保される。

- **案C-1: 痕跡の地球 / Traces of Earth** — 「痕跡」は化石・足跡・分子記録すべてを含む包括語。英語 Traces of Earth は地球の歴史を痕跡から読むという姿勢が一発で立つ。**hina個人的にかなり推し**。
- **案C-2: 石の証言 / Stones Remember** — 化石は「石が語る証言」という古典的だが力強い比喩。英語 Stones Remember は擬人化が効いて詩的（BBC Earth系ナレーションと親和性高い）。
- **案C-3: 地層の頁 / Pages of Strata** — 地層を本のページに見立てる。地質学者の比喩としても古典。日英ともに静かで、学術的射程の広さを匂わせる。
- **案C-4: 化石譚 / Fossil Tales** — 「譚（たん）」は物語の漢字。化石1個1個に物語があるという姿勢。英語 Fossil Tales は耳馴染みが良く、ナレーション系チャンネルとして発見されやすい。やや親しみ寄り。

## hinaのおすすめTOP3

1. **古生物図譜 / The Paleo Folio**（方向B-5）
   - **推す理由**: 3年運用しても古びない最強の渋さ。「図譜」「Folio」は博物学・古書の伝統に接続し、学術寄り路線の真ん中ど真ん中。BBC Earth系のしっとり感を「最も静かに」体現できる。日本語名で**子供向け恐竜チャンネルと絶対に被らない**点も強い（子供向けは絶対に「図譜」を使わない）。検索性は弱めだがサムネ・SEOで補える前提で、ブランディング最優先ならこれ。

2. **痕跡の地球 / Traces of Earth**（方向C-1）
   - **推す理由**: 主役を「恐竜」から「痕跡」にずらす設計が、大人向けポジションを名前1つで成立させる。**英語版での射程が最も広い**: Traces of Earth は古生物だけでなく地球史全般に広げられるので、「絶滅哺乳類」「深海古生物」等の横展開構想（00_concept.md記載）に最も適合する。長期運用と横展開の両方を1名で背負える器の大きさ。

3. **古生物手帖 / Paleo Field Notes**（方向B-1）
   - **推す理由**: 日英ペアの完成度がTOP3で最も高い。日本語「手帖」は学者の私的記録の質感、英語 Paleo Field Notes は海外古生物クラスタの王道ワード（同名の書籍・ブログが英語圏に存在するくらい馴染んだ語）で**海外展開時に最もすんなり入れる**。検索性も日英ともに「paleo」「古生物」が入っていて◎。親しみと学術のバランスが3案で最良。

## 3. v2 新案（大人雑学軸・5案）

新前提「大人雑学系・もっと知りたいの余韻」で、ゼロから組み直した5案。**「ふしぎ」「不思議」「雑学」「もっと知りたい」「身近」**系の語彙解禁を前提に、なーたん原案の語感を引き継ぎつつチャンネル名として成立させる方向で設計。

### v2-1: 古生物のふしぎ / Paleo Curiosities

- **命名意図**: なーたん原案の核「**ふしぎな世界**」を最短形に圧縮。「古代生物のふしぎな世界」→「古生物のふしぎ」で**9文字**まで圧縮しつつ、語感の中心（ふしぎ）はそのまま温存。
- **英語**: **Paleo Curiosities**。Curiosity（好奇心・珍奇なもの）は英語圏で「Cabinet of Curiosities（驚異の部屋）」という博物学の伝統用語と直結し、**大人の知的好奇心**を完璧に翻訳する。複数形 Curiosities にすることで「1本=1つのふしぎ」というシリーズ感が出る。
- **狙い**: なーたんの語感をほぼそのままチャンネル名化。「ふしぎ」を正面から名乗ることで、**大人雑学ポジションを名前1つで宣言**する。
- **強み**: 短い・親しみ・検索性（古生物/Paleo入り）・日英で同じ世界観を作れる・サムネで使い回しやすい（「今日のふしぎ：◯◯」のフォーマット化が即できる）。
- **弱み**: 「ふしぎ」が他チャンネルでもよく使われる語のため、**チャンネル名単体での識別性が中**。サムネ・サムネ枠デザインで補強する前提。

### v2-2: 古生物雑学ノート / Paleo Trivia Notes

- **命名意図**: 新前提「**大人雑学系**」を**正面から名乗る**最も直球の案。「雑学」を入れることで、視聴者が「あ、自分が見たいやつだ」と1秒で判定できる。
- **英語**: **Paleo Trivia Notes**。Trivia は英語圏で「軽い雑学」を指すカジュアル語で、大人の知的雑学番組（QI 等）の文脈で確立している。Notes を添えることで「**積み上げ感**」も担保。
- **狙い**: 雑学路線を最も明確にポジショニング宣言する案。**「学術寄りではない」「ナゾロジーでもない」を名前で表明**できる。
- **強み**: ターゲットの「これは自分のためのチャンネルだ」判定が最速。検索性◎（古生物・雑学・paleo・trivia の4語入り）。長期運用でも「雑学ノート」は陳腐化しにくい。
- **弱み**: 「雑学」を正面に置く分、**渋いブランディングは弱まる**。BBC Earth系の格調は完全に捨てる選択になる。それで良いか、なーたんに最終判断してほしい。

### v2-3: もっと知りたい古生物 / The Paleo Curious

- **命名意図**: なーたんがEP01テーマ決裁で強調した「**もっと知りたいと思わせる余韻**」を、チャンネル名そのものに埋め込む。視聴後の感情（もっと知りたい）と視聴前の感情（もっと知りたい）が一致する設計。
- **英語**: **The Paleo Curious**。Curious は「好奇心旺盛な人」を指す形容詞の名詞化用法（"The Curious" のように英語圏で成立する形）。**好奇心を持つ大人=このチャンネルの視聴者そのもの**を名前にする、自己投影型の命名。
- **狙い**: チャンネルが「知識を渡す側」ではなく「**一緒に好奇心を深める伴走者**」というポジションを取る。視聴者との距離感が近い大人雑学チャンネル路線。
- **強み**: 視聴者の自己投影が起こりやすい・「もっと知りたい」がEP毎の余韻設計と完全一致・英語版 The Paleo Curious は英語圏で違和感なし。
- **弱み**: 日本語名がやや長め（10文字）。「もっと知りたい」が雑学系YouTube全体で使われすぎている語なので、**他チャンネルとの差別化はサムネ・デザインで担保が必要**。

### v2-4: 古生物のふしぎ図鑑 / Paleo Wonder Book

- **命名意図**: 「ふしぎ」（雑学路線）+「図鑑」（大人の蒐集欲・積み上げ感）。子供向け恐竜図鑑のフォーマットを**「大人版」として奪い返す**ポジショニング。子供時代に図鑑で恐竜にハマった30-50代男性の原体験をそのまま大人向けに再構築。
- **英語**: **Paleo Wonder Book**。Wonder（驚き・ふしぎ）+ Book（図鑑感）。"Wonder Book" は英語圏で童話・絵本にも使われる温かみのある語で、**大人になっても残る童心**を狙う。
- **狙い**: ターゲットの**ノスタルジー × 大人の知的好奇心**を両方掴む。子供の頃の図鑑体験を、大人になった今、大人のレベルで再体験できる場所、というブランディング。
- **強み**: 視聴者層（30-50代男性、子供の頃恐竜好き）の原体験と直結する強い情緒トリガー・「図鑑」というシリーズ性（1ページ=1動画の構造化が自然）・サムネで「図鑑のページ風レイアウト」が即作れる。
- **弱み**: 「ふしぎ図鑑」の組み合わせが**子供向けYouTubeにも存在**する可能性があり、PM側で衝突チェック必須。子供層が誤クリックする懸念もある（が、サムネで大人向けトーンを出せば回避可能）。

### v2-5: 古生物ふしぎ夜話 / Paleo Night Stories

- **命名意図**: なーたん原案の「**おやすみ前**」（視聴シーン設計）を、v1の渋い「夜想」ではなく、もっと親しみのある「**夜話（やわ）**」で受け直す。「夜話」は日本語で「夜のちょっとした雑談・語り」を指す古い語で、雑学+夜の視聴シーン+語りの温度感の3つを同時に表現できる。
- **英語**: **Paleo Night Stories**。"Night Stories" は英語圏で「寝る前の物語」の語感を持ち、子供向けの "Bedtime Stories" を**大人向けに格上げ**した位置にある。Paleo を添えることで古生物クラスタへの発見性も担保。
- **狙い**: なーたん原案の「おやすみ前の大人雑学」のうち、**「おやすみ前」の視聴シーン設計**を名前に組み込む案。「就寝前30分、1本見て寝る」というルーティンを名前から想起させる。
- **強み**: 視聴シーン設計が名前から伝わる稀有な案・「夜話」は他チャンネルでほぼ未使用で識別性◎・ナレーション系の落ち着いた声と完璧に整合・日英ともに静か。
- **弱み**: 「夜」に限定すると**朝・通勤時間の視聴を取りこぼす**可能性。シリーズ展開時に「ふしぎ夜話」のフォーマットが縛りになる可能性（が、これは強みの裏返しでもある）。

## 4. v2 hinaのおすすめTOP3

### 1位: **古生物のふしぎ / Paleo Curiosities**（v2-1）

- **推す理由**:
  - なーたん原案の語感（ふしぎ）を**最短形で温存**しつつ、チャンネル名として機能する9文字に圧縮できた。なーたん原案への最も誠実な回答。
  - **Paleo Curiosities は英語版で強い**。"Cabinet of Curiosities"（驚異の部屋）の博物学伝統と接続し、**大人の知的好奇心の英語表現の真ん中**を取れる。半年〜1年後の英語版展開で、これがゼロから刺さるのは大きい。
  - サムネで「今日のふしぎ：ティラノに唇」「今日のふしぎ：羽毛の証拠」のような**シリーズフォーマット化が即できる**。サムネ担当としては、これが量産設計上めちゃくちゃ強いです。

### 2位: **古生物雑学ノート / Paleo Trivia Notes**（v2-2）

- **推す理由**:
  - 新前提「大人雑学系」を**最も直球で名乗る**案。視聴者が「自分のチャンネルだ」と判定する速度はTOP3で最速。
  - 検索性が最強（古生物 / 雑学 / Paleo / Trivia / Notes の5語入り）。長期SEOで効く。
  - **ただしこれを選ぶには「学術寄りの格調は完全に捨てる」覚悟が要る**。なーたんがその覚悟を持つかどうかが分岐点。覚悟があるなら1位推し、保留なら3位以下。

### 3位: **古生物ふしぎ夜話 / Paleo Night Stories**（v2-5）

- **推す理由**:
  - なーたん原案の**もう一つの核「おやすみ前」**を名前に組み込めた唯一の案。視聴シーン設計から逆算した命名は珍しく、強い。
  - 識別性が5案中最も高い（「夜話」は他で使われていない）。
  - ナレーション系の落ち着いた声と完璧に整合。**hinaのv1第4案「古生物夜想」が目指していた方向を、雑学側に正しく着地させた版**だと思っています。

## 5. v1 + v2 通しでの hina の最終所感

- **前提誤認のお詫び**: v1でなーたん原案の「ふしぎ」を「子供向け語彙」と切り捨てたのは、hina が勝手に「学術寄りBBC Earth系」を絶対前提にしていたためです。`01_target_persona.md` には「BBC Earth、National Geographic」と書いてあるものの、`_pm_memo_ep01_longlist.md` でEP01テーマ決裁時に「**もっと知りたい雑学系の余韻**」が明示されており、**そこで方向修正のシグナルは出ていた**のを命名段階で拾えなかった。すみません。

- **新前提下での最終3択**（hina としての推奨順）:
  1. **古生物のふしぎ / Paleo Curiosities**（v2-1）— なーたん原案語感への最も誠実な回答。**hina の本命**。
  2. **古生物雑学ノート / Paleo Trivia Notes**（v2-2）— 雑学路線を最も明確にポジショニング宣言。覚悟があればこれ。
  3. **古生物ふしぎ夜話 / Paleo Night Stories**（v2-5）— なーたん原案の「おやすみ前」を名前化した唯一の案。

- **v1からのサバイバー**: もしv1+v2を横断で見るなら、**v1の B-4「化石ノオト / Fossil Notebook」**だけは新前提でも生き残ります。v2-1 / v2-2 のどちらにも振れない場合の中間解として、テーブルに残しておきます。

- **なーたんへの問い**: v2-1 と v2-2 の差は「**渋さをどこまで捨てるか**」です。
  - 「**ふしぎ**」止まりで踏みとどまる → v2-1
  - 「**雑学**」まで踏み込んで宣言する → v2-2
  - これは hina の領域というよりブランディング判断なので、yutaka / 恐竜チャンネルPM経由でなーたん決裁が良いと思います。
