## 1. manami（台本・リサーチ）レビュー観点

manami は本チャンネルの**学術精度の最前線**かつ**雑学トーンの作り手**。PMが最も時間をかけてレビューする相手。

### 1-A. リサーチ・ファクト

| # | 観点 | 判定基準 | PMの口癖（差し戻し例） |
| --- | --- | --- | --- |
| 1-A-1 | 一次情報の所在 | 査読論文・学会発表・専門書籍まで降りているか。Wikipedia・キュレーションサイト止まりではないか | 「これWikipediaの孫引きですか？原著当たれそうですか？」 |
| 1-A-2 | 出典の明記 | 概要欄に載せる出典リスト（論文タイトル・著者・年・誌名）が台本末尾に添えられているか | 「概要欄出典欄、テンプレに沿って書いておいてください」 |
| 1-A-3 | 推測・仮説の明示 | 「〜と考えられている」「〜という説がある」「〜という見方もある」と明示しているか。研究者の名前で「○○らは〜と主張している」と帰属させているか | 「ここ、断定になってます。〜とされていますに直してください」 |
| 1-A-4 | 最上級表現の限定詞 | 「最強」「最大」「最古」が裸で使われていないか。「現在知られている中で最大級の」「これまで報告されている中で最古の」等の限定詞がついているか | 「『最大の肉食恐竜』ではなく、『これまでに知られている肉食恐竜の中でも最大級の』に」 |
| 1-A-5 | 反証・別解釈の併記 | 主流説だけでなく、対立仮説・少数派意見にも触れているか（**学術精度の差別化ポイント**） | 「ここ、別解釈もあると思うんですが、一行触れられそうですか？」 |
| 1-A-6 | 過去研究との関係 | 「○年に発表されたこの新研究は、それまでの〜という見方を覆した」のように、**研究の流れ**が示されているか | 「いきなり新説から入らず、旧説→転換→新説の3段で組めますか？」 |
| 1-A-7 | 学名・年代表記 | 学名はラテン語表記（*Tyrannosaurus rex* 等）。年代はMa（百万年前）併記。本文中の口頭言及は「ティラノサウルス」でOKだが、概要欄・テロップは学名を残す | 「学名、初出時だけでもイタリック・ラテン併記にしてください」 |

### 1-B. トーン・文体

| # | 観点 | 判定基準 | PMの口癖 |
| --- | --- | --- | --- |
| 1-B-1 | 大人の雑学系トーン | 「ふしぎ」「意外」「ちょっと」「もっと知りたい」等の解禁語彙が**自然に**使われているか。逆に「衝撃」「ヤバい」「最強」が混入していないか | 「ここ『衝撃』ではなく『意外』『ふしぎ』で書けますか？」 |
| 1-B-2 | 文長と読み上げやすさ | 一文が読み上げで詰まらない長さか（目安: 60字以内）。「えー」「あー」が入る癖がないか | 「ここ一文が長いので2文に割って」 |
| 1-B-3 | 数字と固有名詞の散らし | 「○年前」「○m」「○種」等の具体数値、固有名詞が散りばめられているか。情報密度が抜けていないか | 「数値情報少なめ。1本につき5-7個入れてください」 |
| 1-B-4 | 結論先出し→理由→具体例→次へ | manami の文体ベース（manami_profile.md）に従っているか | — |
| 1-B-5 | 子供向け迎合の不在 | 「みんな知ってる○○くん」「すごいんだ！」のような子供向けのテンションが混入していないか | 「これ子供向けトーン入ってます。大人向けに」 |
| 1-B-6 | 視聴者の知的尊重 | 「実は〜なのです（知らないですよね？）」のような視聴者を見下す構文になっていないか | 「視聴者の方が詳しい可能性もあるので、断定の前置きは控えめに」 |

### 1-C. 構成・フォーマット

| # | 観点 | 判定基準 |
| --- | --- | --- |
| 1-C-1 | 尺の妥当性 | 10-15分尺の想定文字数（約3,000-4,500字、句読点・改行込み）に収まっているか |
| 1-C-2 | 構成テンプレ準拠 | オープニング（0:00-0:30）→ 導入（〜1:30）→ 本編3セクション（〜12:00）→ クロージング（〜14:00）→ CTA（〜15:00）の構造を踏襲しているか |
| 1-C-3 | オープニングのフック | 30秒以内に「今日扱うふしぎ」が提示されているか。「○○が△△だった、というのをご存知ですか」型 |
| 1-C-4 | 本編3セクションの設計 | ①基礎知識 → ②最新研究・新発見 → ③解釈・考察 の3段構造が守られているか |
| 1-C-5 | クロージングの余韻設計 | 「もっと知りたい」を引く問いかけが置かれているか。完結しすぎず、次回への自然な接続があるか（→ 次回予告と関連動画への動線） |
| 1-C-6 | テロップ案の同梱 | 重要キーワード・学名・数値はテロップ案として`【テロップ: ○○】`形式で台本に併記されているか（junki・nishiへの引き継ぎを楽にする） |
| 1-C-7 | 視覚指示の併記 | 「ここで○○の図解を入れたい」「ここは復元画」「ここは Seedance 全身カット可」等、映像指示が`【映像: ○○】`形式で併記されているか |

### 1-D. EP01特有のチェック（初回限定）

| # | 観点 | 判定基準 |
| --- | --- | --- |
| 1-D-1 | 主要恐竜が主役か | スター級（ティラノ・トリケラ・ヴェロキラプトル等）が主役になっているか。マイナー種・翼竜から始めていないか |
| 1-D-2 | 意外性の鮮明さ | 「子供向け図鑑では語られない、大人だから楽しめる切り口」が初手で明確か |
| 1-D-3 | チャンネル世界観の打ち出し | 初回として「このチャンネルは何をやるのか」が、視聴者に明示・暗示の両面で伝わる構造か |

## 2. nishi（映像生成）レビュー観点

nishi のアウトプットは**Seedance生成カット**と**画コンテ全体設計**の2層。PMは特に学術整合性と破綻リスクを見る。判定基準の詳細は `analytics/seedance_quality_log.md` に既に蓄積中。本リストはレビュー時の上位観点。

### 2-A. 個別カットの学術整合性

| # | 観点 | 判定基準 | 即NG例 |
| --- | --- | --- | --- |
| 2-A-1 | 解剖学的整合 | 手の指の本数（ティラノ2本、ヴェロキラプトル3本等）、歯列、頭骨形状が誤っていないか | ティラノが指3本／ヴェロキラプトルが2本 |
| 2-A-2 | 羽毛・体表 | 羽毛恐竜（ヴェロキラプトル、ユウティランヌス等）が無羽毛のジュラシック・パーク型になっていないか | ヴェロキラプトルがツルツル肌 |
| 2-A-3 | 運動様式 | 二足歩行種が四足になっていないか／逆も。翼竜の翼指構造、前肢の可動域が破綻していないか | プテラノドンが鳥のように直立／翼が普通の鳥翼 |
| 2-A-4 | 時代考証 | 同じカットに別時代の種が共存していないか（ティラノとアロサウルスは別時代、等） | 白亜紀末と中生代前期種の混在 |
| 2-A-5 | 環境描写 | 草原に被子植物が繁茂しすぎていないか（白亜紀後期以前は被子植物の繁栄度が低い）、現代的な針葉樹の混入 | — |

### 2-B. 破綻リスクの3層運用

PMは生成カットを以下の3層で判定する。

| 層 | 判定 | 運用 |
| --- | --- | --- |
| 1. 学術OK・破綻なし | ◎ そのまま採用 | フル尺で使ってOK |
| 2. 軽度破綻あり | ○ 短尺カット化 | 1-2秒以内・引き画限定・別カットとローテーション |
| 3. 重大破綻 / 学術NG | × 採用不可 | 図解・復元画・化石写真に差し替え（**ここは絶対譲らない**） |

### 2-C. 画コンテ全体設計

| # | 観点 | 判定基準 |
| --- | --- | --- |
| 2-C-1 | カット種類のローテーション | Seedance全身 / 図解 / 復元画 / 化石写真 / テキスト画面 等が**バランスよく**配されているか。Seedance連投で破綻が目立たないか |
| 2-C-2 | ナレーションとの非冗長 | ナレーションが言っていることと**同じ意味**の映像になっていないか（nishi の設計哲学「言葉と映像で同じことを言わない」に沿っているか） |
| 2-C-3 | テンポ | 3-5秒に1カットの切り替えがあるか。冗長な長回しがないか |
| 2-C-4 | テロップ位置 | 英語版差し替え時に文字差し替えだけで成立するレイアウトか（テロップを映像の上に焼き込んでいないか） |

### 2-D. 雑学路線への対応

| # | 観点 | 判定基準 |
| --- | --- | --- |
| 2-D-1 | 親しみのある画作り | 学術寄り時代の「BBC Earth風の暗く荘厳」一辺倒ではなく、明るめ・親しみあるトーンも混ぜているか |
| 2-D-2 | 「ふしぎ」の演出 | 意外性のあるシーン（普通と違うサイズ感／日常物との対比／復元画と化石の対比）が**意識的に**選ばれているか |
| 2-D-3 | 煽り演出の回避 | 効果音的なカメラの寄り・赤フラッシュ・ホラー演出が混入していないか |

## 3. junki（編集・音声）レビュー観点

junki のアウトプットは**音声合成データ**と**編集済み動画**の2層。PMは特にトーン整合と英語版差し替え可能性を見る。

### 3-A. 音声合成（fish audio 系）

| # | 観点 | 判定基準 |
| --- | --- | --- |
| 3-A-1 | 声質トーン | 落ち着いた語り口の声質が選定されているか。煽り系の高速・高揚トーンになっていないか |
| 3-A-2 | 読み速度 | 標準的な解説速度（1分あたり300-350字）に収まっているか。早すぎて雑学の余韻が出ないテンポになっていないか |
| 3-A-3 | 学名・カタカナの読み | 「ティラノサウルス」「プテラノドン」「白亜紀」等が正しく読まれているか。読み間違いを字幕で補完しているか |
| 3-A-4 | 句読点での息継ぎ | 不自然な切れ目がないか。長文を一気読みして詰まっていないか |
| 3-A-5 | 「えー」「あー」の混入 | AI音声特有のフィラーが混入していないか |

### 3-B. 編集（カット・テロップ・SE・BGM）

| # | 観点 | 判定基準 |
| --- | --- | --- |
| 3-B-1 | テンポ | 3秒に1度の変化（カット・テロップ・SE・BGM）があるか（junki の設計哲学準拠）。**ただし雑学路線では投資ch ほどテンポを刻みすぎない**。雑学の余韻を出すため、たまに「2-3秒の静かなカット」を入れる |
| 3-B-2 | 字幕の網羅性 | 全ナレーションに字幕がついているか。学名・カタカナ・固有名詞の誤字がないか |
| 3-B-3 | BGMトーン | しっとり系・落ち着いた弦楽 or アンビエント中心になっているか。煽り系のドラム・EDM系が混入していないか。CC0またはライセンスクリア素材か |
| 3-B-4 | SE使用の節度 | 効果音の多用がないか。「ジャーン！」「ドーン！」のような煽りSEが入っていないか |
| 3-B-5 | ラウドネス | -14 LUFS 目安に収まっているか |
| 3-B-6 | AI開示 | 「AI音声・AI生成映像を含む」開示が動画冒頭または概要欄にあるか |

### 3-C. 英語版差し替え可能性

| # | 観点 | 判定基準 |
| --- | --- | --- |
| 3-C-1 | プロジェクト構造 | ナレーション音声トラックだけ差し替えれば英語版が成立する構造になっているか（音声トラックが独立、テロップが別レイヤー） |
| 3-C-2 | 字幕レイヤー独立 | 字幕が映像に焼き込まれず、独立レイヤーで管理されているか |
| 3-C-3 | BGM・SEは共通 | 言語に依存しないBGM・SEを使い、日英共通で流用できる構造か |

## 4. hina（サムネ・タイトル）レビュー観点

hina のアウトプットは**サムネデザイン**と**タイトル案**の2層。PMは特にクリック獲得と「煽らずに引く」の両立を見る。

### 4-A. サムネ

| # | 観点 | 判定基準 |
| --- | --- | --- |
| 4-A-1 | スマホ可読性 | スマホ画面サイズで「1秒で誰のための動画か」が伝わるか（hina の設計哲学準拠） |
| 4-A-2 | 配色 | 雑学路線への振り直しに伴い、**学術寄り時代の暗い深緑・茶・青一辺倒は捨てる**。落ち着いた色調を基調としつつ、親しみのある明度・彩度を持っているか。子供向けYouTubeの「赤・黄・ビックリマーク多用」は引き続きNG |
| 4-A-3 | 文字情報 | 文字は最小限（目安: 7-9文字以内のキャッチ + 数字 or 学名）。文字過多のサムネになっていないか |
| 4-A-4 | 主要被写体 | 恐竜の復元画 or Seedance生成カット or 化石写真のいずれかが**1点だけ**主役として配置されているか。ごちゃごちゃしていないか |
| 4-A-5 | 「ふしぎ」の引き | 「？」「ふしぎ」「意外」を示唆する視覚要素（クエスチョンマーク・意外な対比・スケール表示）が**控えめに**1つは入っているか |
| 4-A-6 | 言語非依存レイアウト | 文字差し替えだけで英語版が成立するレイアウトになっているか。文字が映像の重要部分を隠していないか |
| 4-A-7 | NG表現 | 「衝撃」「ヤバい」「最強」「闇」「サイコパス」「禁断」等のNG語彙、過剰な赤フラッシュ・ビックリマーク・人物の驚き顔合成が混入していないか |
| 4-A-8 | サムネ枠デザイン | チャンネル統一サムネ枠（hina と打合せ予定）に沿っているか。EP番号・チャンネル名の表記が一貫しているか |

### 4-B. タイトル

| # | 観点 | 判定基準 |
| --- | --- | --- |
| 4-B-1 | 構文テンプレ | 「○○の新発見 — 2026年の研究で分かったこと」「○○の意外な生態」「○○のふしぎ — △△だった可能性」等の構文ベースか |
| 4-B-2 | 数字 or 固有名詞 | タイトル内に数字 or 固有名詞（学名・年代）が**最低1つ**入っているか |
| 4-B-3 | NG語彙 | 「衝撃」「ヤバい」「最強」「闇」「サイコパス」「禁断」等が混入していないか |
| 4-B-4 | 長さ | スマホ表示で省略されない範囲（目安: 全角28-32文字以内）に収まっているか |
| 4-B-5 | 釣り回避 | サムネ・タイトルが内容と整合しているか（hina の設計哲学「釣りはしない、引きはする」） |
| 4-B-6 | ノスタルジー × 知的好奇心 | ターゲット（30-50代男性、子供の頃恐竜好き）の**ノスタルジー × 大人の知的好奇心**の両面を引けているか |

## 6. 差し戻しの言い方（PM 内部ルール）

差し戻しは事務的に・具体的に・敬意を持って。

- **○ 良い差し戻し**: 「ここ、Wikipediaの記述に近いので、原著（Cullen et al. 2023）の Figure 3 で歯の摩耗パターンを再確認してから書き直してもらえますか。論点だけ箇条書きで上げてくれれば、PMで先行確認します」
- **× 悪い差し戻し**: 「もう少し雑学っぽくしてください」「もう一回」「だめです」

ルール:
1. 何が問題か（事実 / トーン / 構成のどれか）を最初に明示する
2. なぜ問題か（ADR-006の○○違反 / 学術精度の○○ / KPIへの寄与が薄い等）を1行で書く
3. どう直してほしいかの**具体例**を1つ以上添える
4. 担当の判断に委ねる範囲を明示する（「ここはお任せします」「ここは PM 決定です」）
