# KPI と目標

> 本ファイルは [ADR-006](../../decisions/ADR-006_dinosaur_channel_tone_pivot.md)（トーン軌道修正: 学術寄り → 大人の雑学系）と 2026-06-02 戦略変更（英語版展開 一旦保留 / `meetings/2026-06-02_english_version_suspension.md`）を反映した恒久版です。**日本語版単独で成立するKPI設計**に再構築。「海外視聴比率」は将来の英語版再開判断材料として指標としては継続監視するが、英語版立ち上げタイミング・収益合算等の判断ロジックは凍結。

## ノーススター指標

**平均視聴維持率**（雑学トーンに振っても、深く見てもらえているかが命）

## 主担当KPI（恐竜PM週次／月次監視）

| KPI | 説明 | 重要度 |
| --- | --- | --- |
| **平均視聴維持率** | 10-15分尺の維持率、特に中盤の離脱点 | ★★★（ノーススター） |
| **平均視聴時間** | 尺10-15分に対しての絶対時間 | ★★★ |
| **総再生時間** | 広告収益の本丸 | ★★★ |
| **インプレッションCTR** | サムネ・タイトルの引き |  ★★ |
| **再生リスト保存率・ベル通知ON率** | コアファン化指標 | ★★ |
| **書籍アフィリのCTR・成約** | 古生物書籍は意外と動く市場 | ★★ |
| **海外視聴比率** | 将来の英語版再開判断材料（指標監視のみ） | ★（凍結） |

監視サイクル: 急ぐ指標ではないので**週次は軽め・月次でじっくり**振り返る。月次で `analytics/monthly_{YYYY-MM}.md` に蓄積。

## 品質検証フェーズの目標（2026-06〜）

- Seedance での恐竜映像 5体分の品質検証完了
- 1分尺の試作映像 1〜2本
- コスト・生成時間データの収集
- 学術整合性の判定基準を `analytics/seedance_quality_log.md` に蓄積（恐竜PMの番人ルール）

## 立ち上げ期の目標（本格運用開始〜3ヶ月）

- チャンネル登録者: **500人**（投資chの半分目安、量より質）
- 月間総再生時間: **2,000時間**
- 投稿本数: **12本**（週1本ペース）
- 平均視聴維持率: **50%以上**（雑学トーンでも深掘り型なので高めを狙う）
- 平均視聴時間: **6分以上**（尺10-15分に対して）

## 成長期の目標（4〜12ヶ月）

- 収益化達成: **2027-03目安**（投資chより半年遅れる前提）
- 月間収益: 12ヶ月後 **5-15万円**（日本語版単独・あくまで仮）
  - 内訳目安: YouTube広告 3-10万円 / 書籍アフィリ 1-3万円 / メンバーシップ 0-2万円
- 常緑ストック数: 30-50本（2-3年後も検索流入が来る本数）

## 動画単位のKPI（公開後3ヶ月時点の評価基準）

- **インプレッションCTR**: **4%以上**（雑学ジャンルでは中庸、煽らない設計のため低めでも許容）
- **視聴維持率（平均）**: **50%以上**
- **平均視聴時間**: **6分以上**
- **ベル通知ON率・再生リスト保存率**: 投資chより重視（コアファン化指標）

## 撤退ライン

- **品質検証フェーズで**:
  - Seedance の恐竜映像が「視聴に耐えない」レベルなら、本格化を延期 or 別ツール検討（ADR起案）
- **本格運用 6ヶ月時点で**:
  - 登録者300人未満 かつ 平均視聴維持率 35%未満 → 大幅リブランド or 撤退検討
  - 雑学化が伸び悩んだ場合、ADR-006「将来見直しトリガー」に従ってトーン再振り直し検討

## 凍結中の指標・目標（参考・将来再活性化候補）
