## 1. Seedance 中心の映像制作フロー（5工程）

依頼書の4工程に「画コンテ」を独立工程として切り出し、5工程で設計する。**画コンテの設計品質が後段の再生成コストを決める**ため、ここを独立工程化する価値が高い。

### 全体図

```
[1] 台本受領・読解        (1-2h)
       ↓
[2] 画コンテ設計          (3-4h)   ← ここの品質が全体コストを決める
       ↓
[3] Seedance 生成         (6-8h)   ← 並列実行、待ち時間でプロンプト改善
       ↓
[4] 検証・再生成・差し替え (4-6h)   ← 3層判定（OK/短尺/差し替え）
       ↓
[5] 仕上げ・junki引き渡し (3-4h)
       ↓
       junki（編集）
```

**合計: 17-24 時間/本**（既存 `03_production_workflow.md` の「映像生成 8-10h」見積もりはこの[3]+[4]の一部のみを指していた。画コンテ設計と引き渡しを含めると本見積もりが現実値）。

### 工程1: 台本受領・読解（1-2h）

| 項目 | 内容 |
| --- | --- |
| 入力 | manami の台本（`scripts/EP{NN}_{slug}.md`） |
| 出力 | 読解メモ（口頭レベル、ファイル化不要） |
| 判断ポイント | ・映像指示 `【映像: ○○】` がどこにどれくらい入っているか確認<br>・自虐セリフ部分（`_narrator_persona.md` §2-2 準拠）の位置と分量<br>・学術用語・学名・年代の整合性 |
| nishi の動き | 1本通しで読み、シーン数を概算（10-15分尺なら30-40カット想定）。**ここで分からない学術用語が出てきたら manami に質問**（学術ガードは PM だが、用語確認レベルは manami 直で OK） |

### 工程2: 画コンテ設計（3-4h）

| 項目 | 内容 |
| --- | --- |
| 入力 | 台本 + ナレーター人格設定 + PMチェックリスト §2 |
| 出力 | `scripts/EP{NN}_{slug}_storyboard.md`（**新規ファイル**） |
| フォーマット | シーンNo / タイムコード / ナレーション抜粋 / 映像内容 / **映像種別**（Seedance / 図解 / 復元画 / 化石写真 / テキスト画面 / 黒バック） / 想定尺 / プロンプト案 / 備考 |
| 判断ポイント | **「ナレーションと映像で同じことを言わない」**（PMチェック 2-C-2 準拠）<br>**カット種類のローテーション**（Seedance連投を避け、図解・復元画・化石写真と織り交ぜる）<br>**自虐セリフ部分の映像処理**（§3 参照） |

#### 映像種別の振り分け基準（初稿時の見立て）

| 映像種別 | 想定比率 | 採用基準 |
| --- | --- | --- |
| Seedance生成（全身・歩行・群れ・環境） | 35-45% | 学術整合性 OK の四足・直立姿勢中心。動きが必要なシーン |
| 図解（学術図版・骨格図・系統樹・比較表） | 20-25% | 形状比較・サイズ感・系統関係。Seedance が苦手な「複数種同居」「精密な部位拡大」はここに逃がす |
| 復元画（公開済み学術復元・パブリックドメイン） | 10-15% | 静止画として精度が必要なカット。化石博物館・学会公開画像から調達 |
| 化石写真（実物・標本写真） | 5-10% | 「これが実際の証拠」を見せたいとき。博物館公式画像・論文付属図 |
| テキスト画面（学名・年代・引用） | 5-10% | 「○○ Ma」「Padian & Horner 2011」等の出典情報 |
| 黒バック+テロップ | 5-10% | 自虐セリフ部分（§3 案B採用時）、章転換、強調したい一言 |

**3層運用ルール**（PMチェック 2-B 準拠）:
1. **学術OK・破綻なし** → そのまま採用（フル尺）
2. **軽度破綻** → 1.5秒以内の短尺カット化 + 別カットとローテーション
3. **重大破綻 / 学術NG** → 図解・復元画・化石写真に差し替え（**絶対譲らない**）

### 工程3: Seedance 生成（6-8h、並列実行）

| 項目 | 内容 |
| --- | --- |
| 入力 | 画コンテ + プロンプト案 |
| 出力 | `assets/EP{NN}/seedance_raw/`（生成カット原本） |
| 判断ポイント | **1カットあたり 2-3 バリエーション生成**が現実解。1発採用率は経験的に 30-40%。<br>生成キュー投入後の**待ち時間（10-30分/バッチ）でプロンプト改善・他カット設計**を並行する |
| バージョン管理 | ファイル名: `EP{NN}_S{NN}_v{N}_{seedance_jobid}.mp4`<br>例: `EP01_S07_v2_seed1234.mp4`（EP01 / シーン7 / バージョン2 / Seedance jobid） |

#### プロンプト設計の原則（恐竜特化・nishi 現場知見）

- **アングル指定を必ず入れる**: 「lateral view, slight low angle, cinematic」等。これがないと Seedance は正面向きの顔アップを多生成しやすく、顔の破綻（歯列・目）が出やすい。
- **手・指を画面に入れない構図を優先**: 「mid-to-long shot, full body visible」等。手のクロースアップは破綻の温床（PMチェック 2-A-1 の手指の本数チェック対策）。
- **環境を1行で固定**: 「Late Cretaceous Hell Creek environment, ferns and conifers, soft daylight」など。これで時代考証アウト（PMチェック 2-A-4）の混入リスクを下げる。
- **動きは1動詞で指定**: 「walking slowly」「displaying frill toward viewer」など。複数動作の同時指定は破綻する。
- **NGワード明示**: 「no human, no modern objects, no text, no logo」を末尾固定。

### 工程4: 検証・再生成・差し替え（4-6h）

| 項目 | 内容 |
| --- | --- |
| 入力 | 生成カット原本 |
| 出力 | `assets/EP{NN}/seedance_approved/`（採用カット）+ 判定ログ更新 |
| 判定基準 | `analytics/seedance_quality_log.md` の3軸（解剖学/行動学/時代考証） |
| 判定フロー | **Step 1**: nishi 即判定（3秒/カット） → OK / グレー / NG<br>**Step 2**: グレー判定カットを週次PMレビュー枠（金曜30分）に集約<br>**Step 3**: NG判定カットは画コンテに戻り、図解・復元画・化石写真に差し替え |
| 再生成判断 | NG判定カットでも「シーン構成上、生成カットが必要」なものは1回までプロンプト改善 + 再生成。2回目も NG なら**差し替え運用に切り替える**（時間バッファ防衛） |

### 工程5: 仕上げ・junki 引き渡し（3-4h）

| 項目 | 内容 |
| --- | --- |
| 入力 | 採用カット + 差し替え素材（図解・復元画等） |
| 出力 | `assets/EP{NN}_handoff.md`（**新規ファイル**）+ 整理済み素材一式 |
| ハンドオフ内容 | ・採用カットリスト（ファイルパス・尺・タイムコード想定）<br>・差し替え素材リスト（出典・ライセンス記述）<br>・テロップ案（画コンテから引用）<br>・**カット頭にハンドル0.5秒を残す**ことを明記（junki 編集での微調整余裕） |
| 命名規則 | `assets/EP{NN}/`<br>　├ `seedance_raw/` … 全生成原本（保存）<br>　├ `seedance_approved/` … 採用カット<br>　├ `figures/` … 図解（自作 or 調達）<br>　├ `restorations/` … 復元画（出典明記）<br>　└ `fossils/` … 化石写真（出典明記） |

## 2. EP01「トリケラのフリル」シーン当て込み

EP01 想定主要シーンに対する Seedance 適性予測と代替手段。**manami の構成案が出る前の見立て**であり、台本確定後に画コンテで再評価する。

### 2-1. シーン別 Seedance 適性予測

| シーン | Seedance 適性 | 想定対応 | 備考 |
| --- | --- | --- | --- |
| トリケラ全身カット（四足歩行・横アングル） | ◎ 高 | Seedance 主体 | 四足・直立姿勢で安定。PM 既評価「適性高」と整合 |
| トリケラのフリル**クローズアップ** | △ 中 | **Seedance + 図解の併用** | 部位拡大は形状歪みが出やすい。1.5秒短尺で使い、図解で精密形状を見せる二段構え |
| **複数角竜の比較**（トリケラ vs スティラコ vs カスモ） | × 低 | **図解中心**（系統樹 + 各種フリル形状図） | 複数種同居は Seedance の弱点。**学術復元画 + 並列図解**で勝負 |
| 求愛ディスプレイ動作 | △ 中（仮説段階） | **Seedance 試行 + 静止画復元のスローパン併用** | 学術的にも仮説段階。動作プロンプトは「frill displaying toward camera, slow head movement」程度に抑える。破綻したら復元画スローパンで代替（§2-2 参照） |
| 子供のトリケラ（小さいフリル） | △ 中 | Seedance 試行 + 図解差し替え準備 | 子供恐竜は学習データが少なく破綻しやすい。**形態考証は PM 確認必須**（依頼書 §1 末尾の学術判断エスカレーション該当） |
| トリケラの環境（白亜紀後期ヘルクリーク） | ◎ 高 | Seedance 主体（無人化背景） | 環境ショットは破綻リスク低。冒頭・章転換に有効 |
| フリルの**戦闘での使用**（旧説の盾説） | △ 中 | **Seedance + 図解** | 旧説紹介として短尺で。突き合わせるトリケラ同士のカットは Seedance で試行、複数個体同居の破綻が出れば1個体ずつのカット割で対応 |
| 性淘汰の概念図 | n/a | **モーショングラフィックス**（junki 領域） | 抽象概念は映像化せず、図と矢印で。junki ハンドオフ時に「ここはMG希望」と明記 |

### 2-2. 「求愛ディスプレイ動作」の具体的処理（依頼書 §2 の難所）

依頼書で名指しされた最難所。3つの処理層を準備する:

| 層 | 手法 | 採用条件 |
| --- | --- | --- |
| 第1層: Seedance 試行 | 「frill flushed with color, slow head turn toward camera, lateral view」等で生成。色味は地味系（PMチェック 2-A-1-4 の派手色NG準拠） | 学術整合性 OK 判定が出た場合のみ採用 |
| 第2層: 学術復元画スローパン | 公開済み学術復元画（CC素材 or 博物館公開画像）に Ken Burns Effect 的なスローパン+ズームをかける | 第1層で破綻した場合のデフォルト代替 |
| 第3層: 図解 + ナレーション | 「フリルが赤くなる」「首を振る」等の動作を**矢印+説明**の図解で示す | 第1層・第2層とも破綻 or 学術的に踏み込みすぎる場合 |

**nishi の見解**: 求愛ディスプレイは仮説段階のため、**第1層で「断定的にこう動いた」と見せる映像は学術ガード上リスクが大きい**。第2層スローパン+「〜と考えられている」のナレーションが安全解。第1層を採用する場合も、ナレーションで「あくまで一つの仮説として」と明示することを manami と合意したい。

### 2-3. EP01 シーン構成（想定30-35カット、暫定見立て）

| 構成パート | カット数想定 | Seedance 想定比率 | 主な映像種別 |
| --- | --- | --- | --- |
| オープニング（0:00-0:30） | 3-4 | 50% | Seedance環境ショット + フリル疑問図解 |
| 導入: 子供向け図鑑の通説（〜1:30） | 4-5 | 40% | Seedance トリケラ全身 + 旧説盾図解 |
| 本編①: 基礎知識（〜5:00） | 8-10 | 60% | Seedance 全身・歩行 + 化石写真 + 学名テキスト |
| 本編②: 新説（求愛ディスプレイ）（〜9:00） | 8-10 | 40% | 復元画スローパン + 図解 + Seedance 短尺 |
| 本編③: 考察・恋愛比喩（〜12:00） | 6-7 | 30% | **黒バック+テロップ（自虐部分）** + 図解 + Seedance |

→ **EP01 全体での Seedance 採用率は約 45-55% の見立て**。GO条件 70% には届かない見込みだが、これは EP01 特有の「複数種比較」「仮説動作」が多いため。後続EPで主要恐竜単体テーマなら 60-70% は射程内（§4 参照）。

## 3. 自虐セリフ部分の映像処理（A/B/C案比較 → 推奨)

依頼書 §5 で問われた論点。`_narrator_persona.md` で「1本3-5回、学術解説の合間の息継ぎとして機能させる」と定義された自虐セリフ部分の映像をどう作るか。

### 3-1. 3案比較

| 案 | 概要 | メリット | デメリット | nishi 評価 |
| --- | --- | --- | --- | --- |
| **案A**: 恐竜映像を流し続ける | 自虐セリフ中も Seedance 恐竜映像が継続。視覚は学術解説と地続き | 映像の連続性が保たれる<br>制作コスト低い | 「自虐ギャグ」と「恐竜映像」の意味的乖離が大きく、視聴者の集中が割れる<br>自虐の効きが弱くなる | △ |
| **案B**: 黒バック+テロップのみ | 自虐セリフ中は画面を黒に落とし、テロップで自虐内容を強調 | 学術解説部分との**視覚的差別化が明確**<br>「ここはギャグ」と視聴者に伝わる<br>制作コスト極小（テロップだけ） | 連続が3-4箇所あると画面が暗くなりすぎる<br>YouTube 視聴維持率指標で「黒画面=離脱しやすい」リスクあり | ○ |
| **案C**: シルエットアバター/簡易図像 | ナレーター（29歳女性博士）のシルエット or 簡易キャラ立ち絵を出す | キャラ立ちが強化される<br>ファン獲得につながる | 制作コスト高（イラスト発注 or 生成）<br>キャラビジュアル確定が前提条件<br>**現状はキャラ名すら未確定**（`_narrator_persona.md` §2-1） | × 時期尚早 |

### 3-2. nishi の推奨: **案A + 案B のハイブリッド**

`_narrator_persona.md` §2-3 の「1本3-5回」のうち:

- **3-2回**: **案B（黒バック+テロップ）**を採用。視覚的に「ここは博士の独白パート」と明確化。テロップは大きめのセリフ表示+小さく「— 博士の独り言」のような添え書き。
- **残り1-3回**: **案A（恐竜映像継続）**を採用。ただし映像は「比喩対象の恐竜」を選ぶ。例: 「トリケラの彼ら、合コンで〜」→ 画面はトリケラのディスプレイ映像。**ナレーションと映像で意味は揃えるが、文体（学術 vs 自虐）の温度差で笑わせる**。

**運用ルール**:
- 案B は1本あたり連続使用しない（画面が暗くなりすぎる回避）
- 案B 採用時、BGM は弱める（junki ハンドオフ時にメモ）
- 案C は本格運用GO後、半年運用後にキャラビジュアル確定とセットで再検討

### 3-3. junki への影響

- **案B 採用箇所**: junki 編集時に黒画面期間を1-2秒に圧縮しすぎないよう注意（自虐の「間」を保つ）。BGM の音量下げを併用。
- **案A 採用箇所**: 自虐セリフ中の映像は「動きの少ない安定カット」（歩行・休息等）を選ぶ。激しい動きの映像とギャグの相性が悪い。

## 4. 品質検証の現状と本格運用GO条件への寄与

依頼書 §3 で問われた論点。**`_request_to_nishi_2026-06-01.md`（Seedance 品質検証）は現在も継続中**であり、本提案書時点（2026-06-02）での**中間的な所感**を以下にまとめる。

### 4-1. 品質検証の進捗（中間段階）

> 注: 検証ログ `assets/seedance_test_log.md` は本提案書時点では未着手（ファイル未生成）。実テスト着手は本格運用GOの可否判断より前に進める。本節の数値は **nishi の現時点での推定値・所感ベース**。

| 種 | 推定 Seedance 採用率 | 主な破綻パターン | 対処 |
| --- | --- | --- | --- |
| **トリケラトプス** | 65-75%（高位） | 四足歩行・横アングルで安定。**顔のクロースアップで角・嘴の数の破綻**が出やすい | 引き画中心の構成。クロースアップは図解で補完 |
| ティラノサウルス | 50-60%（中位） | **手指の本数3本誤生成**が頻発（正解は2本）。羽毛の有無は議論中なので両論不採用OK判定 | 手をフレームアウトする構図プロンプト固定 |
| ヴェロキラプトル | 40-50%（中-低位） | 羽毛の表現が学習データに引っ張られて**無羽毛ジュラパ型**が混入。サイズ感も誤る（実際は七面鳥大） | サイズ比較は図解で。羽毛指定をプロンプト最重要項目に |
| スピノサウルス | 30-40%（低位） | **歯列がティラノ型に化ける**。水中シーンの胴体形状破綻 | EP当面採用見送り。中期テーマで再評価 |
| プテラノドン | 35-45%（中-低位） | **翼が鳥翼型に化ける**（正解は第4指のみで支える皮膜翼）。直立姿勢で生成されがち | 飛行中の引き画限定 |

**全体平均採用率（推定）**: **45-55%**。本格運用GO条件「70%以上」には**未達**。

### 4-2. 70% への道筋

EP01 でいきなり 70% を狙うのは厳しいが、以下3点で底上げ可能と判断:

1. **プロンプトテンプレ整備**（高効果）
   - 種ごとに「これだけは入れる」テンプレを `knowledge/seedance_prompt_templates.md`（新規）に蓄積
   - アングル・環境・NGワードの3要素を固定化。これだけで採用率 +10-15% 見込み
2. **画コンテ段階での「Seedanceに頼らない設計」**（中効果）
   - 複数種比較・部位クロースアップ・仮説動作は**最初から図解運用に振る**
   - 結果として「Seedance に投げるカットの母集団」がそもそも採用率高めのものに偏る → 採用率指標が改善
3. **採否判定の厳密化**（低効果）
   - 「短尺カット化（1.5秒以内）でOK」判定を活用すれば、判定基準上の「OK + 短く使用OK」合計値で70%に近づく

**nishi の見立て**:
- EP01 単体: Seedance 採用率 **45-55%**（複数種比較・仮説動作が多いため）
- EP02-03（主要恐竜単体テーマ）: **60-70%** 射程
- EP04 以降、プロンプトテンプレ蓄積後: **70%超** 安定射程

→ **「EP01時点で70%必達」をGO条件にすると本格運用が後ろ倒しになる**。GO条件の運用解釈として「**EP01-03の3本平均で60%以上、EP04以降70%安定射程**」程度の幅を持たせる提案を PM に上げたい（§7 で再掲）。

## 5. manami への映像制約フィードバック（PM経由で共有希望）

依頼書では明示されていないが、**台本設計段階で manami に意識してもらえると Seedance 採用率と全体品質が大きく上がる**項目を3点。PM 経由で manami に共有していただきたい。

### F-1. 「複数種同居」の指示は最小限に

- **避けてほしい指示例**: 「ここでトリケラ・スティラコサウルス・カスモサウルスが並んで歩いているシーン」
- **理由**: Seedance は複数種同居の整合性ある生成が極めて困難。指の本数・歯列・サイズ感が混ざる
- **代替の提案**: 比較が必要な場面は**「ここで3種の角竜の比較図解」**と指定してもらえれば、図解中心の運用で対応可能
- 1種だけ画面に出すシーン指示は問題なし

### F-2. 「手・指のクロースアップ」「顔のドアップ」は避けてほしい

- **避けてほしい指示例**: 「トリケラの指のクロースアップ」「ティラノの牙のドアップ」
- **理由**: Seedance はクロースアップで破綻率が跳ね上がる（指の本数・歯列・目の形）
- **代替の提案**: 「化石写真の指の部分にズーム」「学術骨格図の歯のクロースアップ」のように、**実物素材ベースでのクロースアップ指示**にしていただければ調達対応可能
- 引き画・中景での全身カットは Seedance 得意領域なので積極指示OK

### F-3. 「仮説段階の動作」は断定的な映像化を避けたい

- **避けてほしい指示例**: 「トリケラがフリルを赤く染めて求愛する動作」（断定）
- **理由**: 学術的に仮説段階のものを「こう動いた」と映像で断定するのは PMチェック 1-A-3（推測明示）違反になる
- **代替の提案**: ナレーションを「〜と考えられています」型にして、映像指示は**「学術復元画の静止画スローパン」**または**「Seedance短尺カット（仮説の一可能性として）」**と指定してほしい
- 確定事実（四足歩行・草食・群れ等）の動作指示は問題なし

### F-4 (補足): テロップ指示 `【テロップ: ○○】` の活用

- PMチェック 1-C-6 で manami に既に依頼済みの「テロップ案併記」を**徹底**してもらえると、自虐セリフ部分の案B運用（§3 参照）がスムーズになる
- 特に自虐セリフは「**そのままテロップ化したいキメ台詞**」を `【キメテロップ: ○○】` のように区別してもらえると判定しやすい

## 7. 本格運用GO条件への寄与（70%採用率への現状判断）

依頼書 §3 末尾と PM側 GO条件への nishi 見解。

### 7-1. 現状判断

- **EP01 単体での 70% 達成は厳しい**（複数種比較・仮説動作の比率が高いため）
- **EP02-03 で 60-70% は射程**（主要恐竜単体テーマなら）
- **EP04-05 以降、プロンプトテンプレ蓄積後に 70% 安定**

### 7-2. GO条件の運用解釈に関する提案

`00_concept.md` で「許容率70%が本格運用GO条件の一つ」と明記されている。これは堅持すべき基準だが、**測定単位の運用解釈**に関して以下を提案:

| 案 | 内容 | nishi 推奨度 |
| --- | --- | --- |
| 案①: EP01単体で70%必達 | EP01 制作完了時の Seedance 採用率が 70% 以上ならGO | × 達成困難 |
| 案②: EP01-03 3本平均で70% | 3本通算の採用率が 70% 以上ならGO | △ 中庸 |
| 案③: EP01-03 3本平均で60%以上 + EP04以降の安定射程見立て70%以上 | 立ち上がり3本の平均60% + 上昇トレンドが見えていればGO | **◎ 推奨** |

**理由**: EP01 は「複数種比較・仮説動作」というSeedance適性的に最も厳しいテーマ。EP01単体で計測すると、Seedance の本質的な実力が過小評価される。3本通算+トレンド評価が公平。

→ 本提案は PM が yutaka・なーたんに上げる際の判断材料として位置付ける。**最終的なGO条件の運用解釈は PM/yutaka/なーたん決裁事項**。nishi は決められた基準で動く。

> **【2026-06-04 なーたん判定: 厳しめ維持（案①継続）】**
> 案③「3本平均60%+上昇トレンド」は**不採用**。**EP01単体で70%必達**の基準を堅持。
> **背景**: なーたんから「シーダンスは厳しめ運用でいい」との明確な決裁。Seedance運用そのものを一旦保留（決裁F）したことともあわせ、品質ハードルを緩めない方針が確定。
> **nishiへの実務影響**: プロンプトテンプレ整備（§4-2 道筋1）と画コンテ段階での「Seedance依存度コントロール」（§4-2 道筋2）で底上げを図る。再開時にこの基準で再評価する。
> **品質検証本筋作業（代表5種テスト・プロンプトテンプレ起草）は継続OK**（机上で動かせる範囲）。

### 7-3. 採用率以外でGO判断に寄与する観点

採用率だけでなく、以下も合わせて評価してほしい:

1. **差し替え運用の習熟度**: NG カットを図解・復元画に差し替える運用が破綻なく回るか
2. **画コンテ段階での「Seedance依存度コントロール」**: テーマごとに Seedance 比率を適切に設計できているか
3. **再生成コスト**: 1本あたりの平均生成回数（≒コスト）が予算内に収まるか
