#### 命名についての決裁ニュアンス（なーたん指示 2026-06-02）

- **「こはく」はひらがな表記で固定**。漢字「琥珀」は不採用。**理由は「可愛さ重視」**（ひらがなのほうが柔らかく、自虐キャラの素っ気なさ・とぼけ感と相性が良い）。
- ローマ字「KOHAKU」表記もPM判断で**併記廃止**とする（漢字不採用方針との整合・可愛さ重視のトーン強化）。サムネ・テロップ・概要欄すべて「こはく」ひらがな単独運用。
- **音声選定・キャラ設計への影響**: 「可愛さ」は容姿の可愛さではなく、**ひらがな表記が持つ柔らかさ・親しみやすさ**を指す。fish audio 選定でも「凛とした博士声」より**「明るく親しみのある声」**を優先する（§3 選定要件と整合）。

#### 「元気・愛嬌」と「29歳女性博士キャラ」の両立点（なーたん決裁 2026-06-04）

なーたん「これくらい元気あって愛嬌ある女の声の方がウケいい」決裁を受け、旧設計「落ち着いた知性」を**「明るく親しみがあるけど学術精度は保つ」**に再定義する。両立点を以下に言語化:

1. **元気・愛嬌は "声の温度"・知性は "中身の精度"** — 声のトーンは明るくフレンドリーでも、語る内容（学術解説・限定詞付きの仮説提示・出典引用）は博士レベルを維持する。つまり「明るい博士」であり、「テンションだけ高い素人」ではない。
2. **若さの含意** — 「29歳」という年齢設定は、ベテラン研究者の重厚さではなく**「博士課程を出たての、研究の最前線にいるフレッシュな若手研究者」**の若々しさと親和。元気・愛嬌は29歳の自然な属性として成立する。
3. **NG演出は引き続き維持** — §2-5 NG演出（絶叫・若者語多用・キャラ会話など）は撤回しない。「元気・愛嬌」は**親しみのある明るさ**であり、ハイテンション・煽り系・若者語の許可ではない。
4. **比喩・自虐との相性** — 元気な声で語られる自虐は「悲壮感のない、笑い飛ばせる自虐」になり、視聴体験としてはむしろ軽くなる。恋愛比喩も「真面目な博士が真顔で恋愛を語る」より「親しみある博士が井戸端会議調で恋愛を持ち出す」のほうがチャンネルトーン（大人雑学・おやすみ前）と整合する可能性が高い。
5. **判断軸の上位**: なーたんの「ウケがいい」を最上位に置く。設計整合性は二次基準。

### 2-2. 自虐の方向性（重要）

**OKな自虐**:
- 恐竜への偏愛が常人離れしている → 「私、休日も論文読んでるんですけど、家族に『また石コロの話?』って呆れられます」
- 古生物学的知識を日常会話に持ち出して引かれる → 「合コンで『私、恐竜の恋愛事情に詳しいんです』って言ったら、男性陣が3秒で目をそらしました」
- 恐竜と自分の比較で恐竜のほうが上 → 「トリケラの彼ら、求愛のために全身の骨を変形させてるんですよ。私、新しい服を買うかどうかで3日悩むのに……」

**NGな自虐**（hina・junki・manami 共有必須）:
- 容姿に関する自虐（顔・体型・年齢そのものをネタにしない）
- 恋愛市場価値を直接下げる自虐（「私はモテないので」「ブスなので」型）
- 既婚未婚／結婚を急ぐ系の自虐（婚活ネタは全カット）
- 男性を敵視する／逆に過剰に媚びる方向の発言
- 「ドン引きされる」のは**恐竜オタクとしての挙動**であり、**女性としての価値**ではない、という線引きを死守

→ 簡単に言えば: 「**恐竜への偏愛がやばい**」 ○ ／ 「**私という女性がやばい**」 ×。

### 2-3. 自虐の分量

**【2026-06-02 改訂・なーたん決裁】** 自虐は「8分に1回ペース／10分尺で2回程度」を目安に大幅減量。**「10分の間に2回あるかないかくらい」**（なーたん語感）が運用基準。

- **基準ペース**: 約 **8分に1回**。10分尺なら**最大2回**、15分尺でも**最大3回**を上限とする。
- **下限は設けない**: 「2回あるかないかくらい」のニュアンスは、無理して2回入れる必要はないことを含意する。**自然に置ける場面が1回しかなければ1回でよい**。"あるかないか"の境界も死守する。
- **配置の作法**:
  - タイミングは作家（manami）任せ。学術解説の流れを切らない位置に置く。
  - 学術解説の合間の「息継ぎ」として機能させる。主役にしない。
  - 連続して自虐を続けない（学術解説 → 自虐1 → 長めの学術解説 → 自虐2 のように、間に厚みのある学術ブロックを挟む）。
- **PMレビュー基準**:
  - 3回以上ある → 原則 REWORK。「キャラ立ち芸人化」のリスクライン。
  - 2回 → 上限。配置の妥当性をチェック。
  - 1回 or 0回 → 自然な流れで成立していれば OK。学術精度・問いかけ・ユーモア以外の規範が満たされていれば、自虐ゼロも許容する。
- **設計の意図**: 旧基準「3-5回／本」は実際の運用感より多すぎ、キャラ立ち芸人系に転びうる構造的リスクを内包していた。**自虐は学術解説の調味料**であり、メインディッシュは依然として学術解説・問いかけ・MECEな論点整理。なーたん語感「2回あるかないかくらい」を素直に拾う運用に切り替える。

### 2-4. 恋愛比喩ギャグの作法

「恐竜の生態 → 人間の恋愛事情への比喩接続」の構造で:

**例（EP01 トリケラのフリル＝求愛ディスプレイ説 で）**:
- 「フリルの形状が種ごとに大きく違うんです。**つまりトリケラの皆さん、合コンで『私はトリケラトプスです』『私はスティラコサウルスです』ってひと目で見分けてもらうために、襟元を派手にしてた**わけですね」
- 「角を伸ばす、フリルを派手にする、色をつける……。**現代の私たちが香水を選ぶのと、たぶん本質は同じ**なんですよ」
- 「ただ違うのは、彼らは全身の骨を変形させてるってことです。**私が口紅の色で1時間悩むのが、ちょっと恥ずかしくなるレベル**ですね」

→ 比喩の方向は「**恐竜が人間と地続きの恋愛アピールをしてた**」ことを示すもの。学術的にも「性淘汰」は人間と恐竜で共通する枠組みなので、**比喩は単なる笑い狙いではなく、性淘汰理論の身近な翻訳としても機能する**。

### 2-4a. 視聴者への問いかけ + 引用元のさらっと紹介（ナレーション設計に直結）

なーたん指示（2026-06-02）の**ライティング規範6点**のうち、ナレーション語り口に直接効くもの2点を再掲。詳細は `_request_to_manami_ep01_2026-06-02.md` §4-A。

- **③ 視聴者への問いかけ**: 「あなたならどう思いますか?」「これって人間でいうと△△ですよね?」型を1本3-5回。自虐セリフと同様、ナレーターが**素っ気なく問いかける**のが本キャラの正解。視聴者を見下ろさない、煽らない、静かに問う。
- **② 引用元のさらっと紹介**: 「○○大学の××教授の研究によると」「△△年の論文では」をナレーションに自然に溶かす。**重い注釈調にしない**のが声の演技ポイント。junki は fish audio で「論文の話を、井戸端会議みたいに軽く触れる」抑揚を意識。

### 3-4. なぜ fish audio なのか（差別化軸の言語化）

- 国内競合（ゆっくり科学系・トリビア系）の多くは VOICEVOX 系のゆっくり音声か、無料の合成音声。**機械っぽさが残る**。
- fish audio は生成AI音声として人間に近い自然さを出せる（2025-2026年時点で頭ひとつ抜けている）。
- 「**機械っぽくない女性ナレーター**」は、当チャンネルの**音声差別化の核**。
- ただし fish audio でも「キャラクター音声化」までやると不自然になりやすい。**ふうかは "ナチュラル寄りの明るい親しみある声"** を選択した結果である（旧「ナチュラル寄りの落ち着いた声」基準は撤回）。

### 3-5. 「おやすみ前」シーン整合性に関するPM見立て（2026-06-04）

ふうか採用に伴い、「おやすみ前の大人雑学」シーン設計と「元気・愛嬌・高速タグのボイス」が両立するかをPMとして検討した結論を以下に記録する。

**A. 整合する派の論拠**
- 「元気」は「騒がしい」ではない。親しみ感・明るさは、寝る前の語り（井戸端会議調・友達の話を聞く感覚）と矛盾しない。
- ふうかタグ「フレンドリー・クリア」は、寝る前にスマホで聴くコンテンツとの相性が良い。**眠気を誘うのは "暗いトーン" ではなく "心理的安心感"**。明るく親しみのある声は、後者の安心感を提供できる。
- 競合の VAIENCE 系・ゆっくり科学系も、必ずしも低音・落ち着きを採用していない。むしろ親しみある明るい声で長尺を回している成功例がある。

**B. 整合しない派の論拠**
- ふうかのデフォルトタグ「高速」が「おやすみ前」の落ち着き・スローテンポと対立する可能性。
- 元気すぎると寝る前の視聴者にとって刺激が強く、リラックスにならない懸念。
- なーたん基準で「速度を落として運用」できるかは、実音声生成して試聴するまで未確定。

**C. PM結論**

**「速度パラメータで調整して整合させる」を採る**。具体的には:
- ふうかのデフォルト速度（高速タグ前提）ではなく、**fish audio の `speed` を 0.85-0.9 で初期検証**する。
- speed 0.85 / 0.9 / 1.0 の3水準でサンプル生成 → 「おやすみ前」シーン整合に最も近い設定をなーたん試聴で確定。
- もし speed 0.85 でも「元気・愛嬌」が消えずに親しみが残れば、整合成立。消えてしまうなら「シーン設計"おやすみ前"そのものを再考」する選択肢に進む（その場合は yutaka 経由で上申）。

**D. シーン設計の解釈アップデート**

「おやすみ前」は**「視聴者がベッドでスマホを見ている時間帯」**の意味であり、**「眠気を誘う朗読」**ではない。親しみある声で語られる雑学を「布団の中で聴く」体験が成立すれば、シーン整合は満たされると再定義する。本見立てを `_pm_status_overview` 側にも反映する。

## 4. 視聴者交流の設計

### 4-1. 自虐とコメント欄の関係

自虐セリフは「**視聴者からの共感コメントを誘発する装置**」として設計する。

- 自虐 → 視聴者「わかる」「同類です」「私のほうがヤバいです」のコメント流入
- ナレーターキャラへの愛着が育つ → リピート視聴・チャンネル登録に直結
- コメント欄でナレーターが「いいね」を押す or 簡単なリプを返す（運用は本格運用GO後に別途設計）

### 4-2. 動画内CTA（クロージング）

「**今日の話、皆さんの恋愛事情と何か重なる部分ありましたか? コメントで教えてください**」型のCTAを EP01 から組み込む。「チャンネル登録お願いします」だけにしない。

### 4-3. 視聴者からの質問・リクエスト回収

- 「次回は皆さんからのリクエストで○○の話をします」型の展開を、5本程度溜まった段階で導入検討
- まずはEP01-3で自虐 + CTAの組み合わせがコメント欄に効くかを見る

| **自虐 ≠ ファクト精度低下** | 自虐セリフはギャグだが、学術解説部分は依然として「〜と考えられている」「〜という説がある」の限定詞・一次情報優先ルールを遵守 |
| **比喩 ≠ 断定** | 「人間の恋愛と同じです」と断定しない。「私たちの恋愛アピールと**たぶん本質は近い**」「**通じるものがある**」のように比喩であることを言語で明示 |
| **キャラ越境禁止** | 古生物学の範囲を超えた断定（心理学・進化心理学・社会学の専門領域）には踏み込まない。「私、恐竜の博士なので人間のことは詳しくないんですけど」と前置きする |
| **キャラ崩壊回避** | キャラの濃さが学術トーンを侵食する場合、PMレビューで自虐を間引く。**主役は学術解説、キャラは調味料** |
