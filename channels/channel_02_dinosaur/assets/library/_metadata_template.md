# 素材メタデータ記録シート

- **目的**: 取得した動画素材1件につき1行記録。ライセンス遵守・再利用判定・概要欄クレジット作成のための1次データ
- **記入者**: なーたん（DL時） / nishi（生成時） / PM（最終チェック時）
- **形式**: 下表に追記方式。新規取得時は表の末尾に1行追加
- **関連**: 運用ガイドは `README.md`、EP01取得チェックは `_ep01_freestock_checklist.md`

---

## 記入ルール

1. **取得・生成した瞬間に1行追記する**（後でまとめてやろうとすると必ず漏れる）
2. ライセンス欄は省略禁止。不明なら「**要確認**」で記入してPMに上申
3. 商用利用NGが判明したらその行は採用不可。ファイルを `_rejected/` に移動して別途記録
4. 既存行を消さない（一度採用した素材を後で再利用する判断材料にする）

## 補助: ライセンス種別の代表例

| ライセンス名 | 商用利用 | クレジット | 改変 |
| --- | --- | --- | --- |
| **Pexels License** | OK | 不要 | OK |
| **Pixabay License** | OK | 不要 | OK |
| **CC0** | OK | 不要 | OK |
| **Mixkit License** | OK | 不要（推奨） | OK |
| **CC-BY 4.0** | OK | **必要**（作者名+ライセンス名） | OK |
| **CC-BY-SA 4.0** | OK | **必要** + **派生物も同ライセンス** | OK（条件付き） |
| **CC-BY-NC** | **NG** | （商用不可） | - |
| **Editorial Use Only** | **NG**（広告・商用不可） | - | - |

→ 「CC-BY-NC」と「Editorial Use Only」は**採用しない**。

## 棚卸しスケジュール

- **月1回**（毎月末）: nishi が全行を見直し → タグ整合性・ライセンス情報の漏れチェック → PMに報告
- **EP公開前**: PMが該当EPで使った素材全件のライセンスを再確認 → 概要欄クレジット作成
