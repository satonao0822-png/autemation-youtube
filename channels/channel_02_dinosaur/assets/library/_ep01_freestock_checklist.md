## 4. 取得時の注意（必ず守る）

### 4-1. ライセンス確認は省略しない

各動画の**個別ライセンス表記**を確認。サイト全体のデフォルトがクレジット不要でも、**個別動画でクレジット必要なものが混じる**ことがある。

### 4-2. ファイル命名は厳守

ダウンロードしたファイルは即座にリネーム:

```
<EP番号>_<シーン番号>_<役割タグ>_<出典>_<尺秒>.mp4

例: ep01_01_opening_starscape_pexels_12s.mp4
    general_g1_sunset_coverr_8s.mp4
```

### 4-3. メタデータ追記は1動画1行

`_metadata.md` に**取得した瞬間に1行追記**。後でまとめてやろうとすると必ず漏れる（運用ガイド §4-1 参照）。

### 4-4. 「商用利用NG」「ライセンス不明」は採用しない

迷ったら捨てる方が安全。後でYouTube著作権ペナルティになると数倍コストがかかる。

### 4-5. 格納フォルダ

| 出典 | 格納先 |
| --- | --- |
| Pexels / Pixabay / Coverr / Mixkit / その他フリー | `01_freestock/<分類タグ>/` |
| Magnific 生成 | `02_magnific/<分類タグ>/` |
| Seedance 生成 | `03_seedance/ep01_triceratops/` |
| GPT Image 2 マスター設定画 | `99_master_keyframes/` |
