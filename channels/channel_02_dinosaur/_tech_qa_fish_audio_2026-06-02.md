# fish audio 技術Q&A（なーたん向け）

- 起案: junki（編集担当）
- 日付: 2026-06-02
- 宛先: なーたん
- 出典: fish.audio 公式 / 公式ドキュメント（docs.fish.audio）/ Smallest.ai レビュー記事（2026年版）

## 0. 三行サマリ（先に結論）

1. **Claude（junki）から自動で動かすことは技術的に可能**。fish audio はAPIキー方式で、`FISH_API_KEY` を環境変数に置けば junki が直接叩けます。手動運用と自動運用の二択ではなく「手動でテスト → 安定したらAPI自動化」が現実的。
2. **料金は完全な従量課金（pay-as-you-go）**。API単価は **100万バイトあたり$15（=日本語1文字あたり約0.045〜0.06円）**。月4本×恐竜だけなら **月50〜70円**、投資ch合算でも **月100〜150円程度** で収まる見込み。価格は誤差レベル。
3. **junkiの推奨**: APIキー方式で自動化に倒す。ただし**声紋ID（こはく）は必ずローカルにバックアップ**しておく（サービス側で消えた時に再学習するため）。

## 1. Q1への回答：「勝手に動かすことできるの？」

### 1-1. 結論

**できます**。ただし「勝手に」の意味を2通りに分けて整理します。

| 運用パターン | 内容 | 誰が動かす |
| --- | --- | --- |
| A. 手動運用 | fish audio の Web画面に人間がログインしてテキストを貼り、再生成 → ダウンロード | なーたん or junki指示書ベースで人間 |
| B. API自動運用 | fish.audio が発行する APIキー を junki（Claude）に渡し、台本ファイルを直接読ませて音声ファイル(.mp3/.wav)を自動生成 | junki（Claude）が単独で完結 |

**用語の補足**: API＝外部システム（fish audio）にプログラム経由で命令を送る窓口。Web画面のボタン操作を、コードから自動化できる仕組み。

### 1-2. B（自動運用）の前提条件

1. **アカウント有**: なーたん既に保有 → OK
2. **APIキー発行**: `https://fish.audio/app/api-keys/` で発行（数クリック）
3. **課金口座の登録**: 従量課金なのでクレカ登録必須
4. **声紋ID（モデルID）の取得**: こはくの声紋を fish audio 上で作成し、その固有ID（例: `abc123def...`）を junki に渡す
5. **APIキーの保管場所**: 後述（セキュリティ）

### 1-3. セキュリティ留意点（重要）

APIキーは「fish audio の財布の鍵」です。漏れると勝手に課金されます。

**置き場所のルール**:
- **置く場所**: プロジェクトルートの `.env` ファイル（git管理外）
  - 例: `FISH_API_KEY=fa_xxxxxxxxxxxxx`
- **絶対に置かない場所**: 
  - `.mcp.json` → これはチーム共有ファイルなのでNG
  - 各 `.md` ファイル → 議事録等に書かない
  - GitHubリポジトリ → push禁止
- **必須対応**: `.gitignore` に `.env` を必ず追加（既存設定で入っていなければ junki が追記します）

**漏洩時の対応**: fish audio 管理画面から該当キーを失効（revoke）して、新しいキーを再発行。これだけで止血できます。

### 1-4. レート制限（参考）

- 無料プラン: 100リクエスト/分
- 有料プラン: 緩和される（公式ドキュメント参照）
- 月4本×2chの運用では絶対に当たらない上限。気にしなくてOK。

## 2. Q2への回答：「APIって従量課金？」

### 2-1. 結論：完全な従量課金（pay-as-you-go）

サブスク強制なし。使った分だけ請求される。**月額固定費0円**。

### 2-2. 料金体系（2026年6月時点）

| 項目 | 単価 |
| --- | --- |
| API 従量単価 | **$15 / 100万バイト**（=$0.000015/バイト） |
| 日本語1文字 | UTF-8で3バイト相当 |
| 日本語換算 | **約$0.000045/文字 ≒ 0.007円/文字**（1ドル=155円換算） |
| 無料枠（Webコンソール） | 月8,000クレジット ≒ 約7分の音声 |
| 月額固定費 | **なし** |

**重要な注意**: fish audio の課金は「文字数」ではなく「**UTF-8バイト数**」基準。日本語は1文字＝3バイトなので、英語より3倍の単価がかかります。これは fish audio 特有のクセ。

### 2-3. 月額試算（恐竜ch運用）

前提:
- EP1本 = 10〜12分尺
- ナレーション文字数 = 約3,500字/本（manami確定値ではない概算）
- 月4本ペース

| 項目 | 計算 | 金額 |
| --- | --- | --- |
| 1本あたり文字数 | 3,500字 | - |
| 1本あたりバイト数 | 3,500 × 3 = 10,500 バイト | - |
| 1本あたりコスト | 10,500 ÷ 1,000,000 × $15 | **約$0.16（24円）** |
| 月4本（恐竜のみ） | $0.16 × 4 | **約$0.63（98円）** |
| 再生成（失敗率20%想定） | ×1.2 | **約$0.76（118円）** |

### 2-4. 投資チャンネル合算試算

| 項目 | 金額 |
| --- | --- |
| 恐竜ch（月4本） | 約$0.76 |
| 投資ch（月4本想定・同尺） | 約$0.76 |
| 月合計 | **約$1.5（230円）** |
| 年合計 | **約$18（2,800円）** |

→ **コストはほぼ誤差**。判断軸として価格は気にしなくて良いレベル。

### 2-5. もしサブスク（Plus/Pro）にした場合の比較

| プラン | 月額 | 含まれる音声時間 |
| --- | --- | --- |
| Free | $0 | 約7分/月（個人利用のみ・商用NG） |
| Plus | $5.50（プロモ価格） | 200分/月（商用OK） |
| Pro | $37.50（プロモ価格） | 1,620分/月（商用OK） |

**重要**: Freeプランは**商用利用NG**。広告収益化を狙うなら、Plus以上 or 従量API（商用OK）を選ぶ必要があります。

**junkiの計算結論**: 月8本×10分=80分なので **Plus（200分・$5.50）が一番ラク** にも見えるが、**API従量のほうが安い**（月$1.5 vs $5.5）。ただしAPI従量の商用利用可否は最終的になーたんがfish audio側の規約を直接確認するのが安全です（後述「次のアクション」参照）。

## 3. junkiの推奨運用方針

### 3-1. 結論：「APIキー自動運用」を推奨

**理由3つ**:
1. **属人化を避ける**: 手動運用だとなーたんが画面に張り付くor junki指示書を毎回出す手間が発生。チャンネルコンセプト（非属人）と矛盾。
2. **コスト同等以下**: 上記試算のとおり、従量APIのほうがサブスクより安い。
3. **再生成が高速化**: 台本の一部修正→該当箇所だけ自動再生成、が秒で回せる。手動だと1分かかる。

### 3-2. 運用フロー（提案）

```
manami（台本確定）
   ↓ .txt or .md でナレーション原稿納品
junki（自動実行）
   ↓ fish audio API でこはく声紋を使って音声生成
   ↓ channels/channel_02_dinosaur/assets/EP{NN}/audio/ に保存
junki（仮編集 → 字幕 → 公開前チェック）
```

### 3-3. ただし手動運用が向くケース

- **EP1の初回だけ**は手動で試したほうが良い：声紋の品質確認、イントネーション調整、こはくのキャラ感の最終チェック
- 初回OKならEP2以降を自動化に切り替え

## 4. 代替案（fish audio が合わなかった場合）

| サービス | 強み | 弱み | 日本語品質 |
| --- | --- | --- | --- |
| **VOICEVOX** | 完全無料・ローカル動作・商用OK | 声の自然さは fish audio に劣る・声紋クローンは別ツール必要 | 良 |
| **ElevenLabs** | 業界標準・声質トップクラス | 料金が fish audio の5〜10倍 | 良〜優 |
| **OpenAI TTS（gpt-4o-mini-tts）** | 安定・安価・APIが綺麗 | 声紋クローン不可（プリセット声のみ）・キャラ性弱い | 中〜良 |
| **にじボイス / Style-Bert-VITS2** | 日本語特化・キャラ性◎ | 商用可否は要確認・運用負荷高 | 優 |

**junkiの見立て**: 現時点では fish audio が「日本語×声紋クローン×低価格」のバランスでベスト。代替案を今動かす必要はないが、**サービス停止リスクのため声紋の元音声（こはくの素材音声）は必ずローカル保管**しておく（fish audio が消えても他サービスで再学習可能にするため）。

## 5. 声紋ID（こはく）の取り扱い

### 5-1. 確保手順

1. fish audio Web画面で「Voice Clone」セクションへ
2. こはくの素材音声（30秒〜数分の高品質サンプル）をアップロード
3. 数十秒で声紋モデルが生成される → 固有ID発行
4. このIDを junki に渡せば、以降は同じこはくの声で何度でも生成できる

### 5-2. リスクと対策

| リスク | 対策 |
| --- | --- |
| fish audio がサービス終了 | 元音声素材を `channels/_template/assets/voice_reference/kohaku/` 等にバックアップ |
| 声紋IDが何らかの理由で失効 | 元音声から再学習。所要時間1分程度 |
| fish audio が規約変更で商用NG化 | 代替サービス（上記）へ移行。元音声があれば移行可能 |

**結論**: 声紋IDよりも「**元になった素材音声**」が本体。これさえあれば何が起きても復旧可能。
