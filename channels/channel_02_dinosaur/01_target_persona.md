# ターゲットペルソナ

> 本ファイルは [ADR-006](../../decisions/ADR-006_dinosaur_channel_tone_pivot.md)（トーン軌道修正: 学術寄り → 大人の雑学系）と 2026-06-02 戦略変更（英語版展開 一旦保留 / `meetings/2026-06-02_english_version_suspension.md`）を反映した恒久版です。当面は日本語圏の30-50代男性中心ターゲットに集中。海外英語圏サブターゲット設計は将来再開時に再活性化。

## メインターゲット

- **年齢層**: 30-50代
- **性別**: 男性中心（70:30程度）
- **居住エリア**: 全国（地方も拾える）
- **職業 / 立場**: 会社員・専門職・教員・研究関連、または恐竜好きの父親層
- **興味関心**: 自然科学、進化生物学、地球史、博物館、雑学・トリビア系コンテンツ
- **YouTube視聴シーン**: 就寝前、休日の昼下がり、作業BGM、子供と一緒に見るケースもある（シーン宣言「おやすみ前の大人雑学」はここに刺さる）
- **視聴トーン嗜好**: 派手な煽りは苦手 / 雑学・ふしぎ系は好き / 学術ガチ勢ではないが知的好奇心は強い

### ペルソナ例

- **加藤さん 42歳 / 男性 / 教員 / 子供あり**
  - 子供の頃から恐竜が好き、最近の最新発見も「ちょっと」気になる
  - 子供と一緒に博物館に行くが、子供向けYouTubeは物足りない
  - 「大人がちゃんと楽しめる、でも論文読まされる感じでもない」レベルの雑学解説を求めている
  - 就寝前にスマホでゆったり見たい
- **吉田さん 35歳 / 男性 / IT企業勤務 / 独身**
  - 学生時代に古生物学に興味を持ったが、専攻ではなく趣味として継続
  - ナゾロジー系の雑学YouTubeをよく見るが、古代生物に特化したチャンネルが意外と少ないと感じている
  - 「ふしぎ」「意外」というキーワードに引かれるが、内容が薄いと冷める

## 視聴動機

- **このチャンネルを開く理由**:
  - 「恐竜・古代生物の意外な話を、煽られずに聞きたい」
  - 「子供向けではない、でも論文っぽくもない、ちょうどいいトーンの解説」
  - 「最新研究の話を、雑学レベルの分かりやすさで知りたい」
- **1本見終わったあとに感じてほしい感情**:
  - 「えっそうだったの、知らなかった」という小さな驚き
  - 「もっと知りたい、次の動画も見たい」という余韻（クロージング設計の中核）
  - 「博物館に行きたくなった」「子供にも話したくなった」

## サブターゲット

- **40-60代男性**（子供の頃恐竜ブーム世代のさらに上 / ノスタルジー強め）
- **20-30代女性**（雑学系YouTube視聴層の一部、ふしぎ系入口で取り込める可能性）
- **海外英語圏の同層**: 2026-06-02 戦略変更により英語版展開そのものが一旦保留。サブターゲットとしての設計も合わせて凍結。再開判断時に再活性化する（指標としての「海外視聴比率」は監視継続）

## 競合・代替手段

### 同じニーズを満たす他YouTubeチャンネル

| カテゴリ | 代表 | 当チャンネルとの距離感 |
| --- | --- | --- |
| 国内・子供向け恐竜系 | 国内多数 | **明確に外す**（大人向けポジション） |
| 国内・最強生物トリビア系 | 国内複数 | **明確に外す**（学術精度を譲らない） |
| 国内・ナゾロジー系雑学 | ナゾロジー他 | **トーンは近い**が、古代生物特化で深掘り |
| 海外・学術ドキュメンタリー | BBC Earth / PBS Eons | 参考にはするが格調は採らない、雑学系の親しみで差別化 |

### YouTube以外の代替手段

- 書籍（恐竜図鑑、Newton等の科学誌、ナショジオ別冊）
- 博物館（国立科学博物館、福井県立恐竜博物館等）
- Netflix「Prehistoric Planet」等のドキュメンタリー

→ 当チャンネルは「**スマホで10-15分・ふしぎな雑学レベル**」というアクセスのしやすさで補完。

## ペルソナ別仮タイトル例（雑学トーン）

雑学路線らしい構文での仮タイトル例。学術寄りすぎず、ナゾロジー寄りすぎない中間を狙う。

- 「ティラノサウルスの意外な日常 — 最新研究で見えてきた本当の姿」
- 「恐竜の色はどこまで分かっているのか — 復元の裏側」
- 「翼竜は鳥ではない — 大人になってから知る進化のふしぎ」
- 「日本でも恐竜は見つかる — 福井で発掘される化石のはなし」
- 「絶滅した古代生物たち — 進化の試行錯誤を物語る5種」
- 「白亜紀末、なぜ恐竜だけが滅びたのか — 鳥が生き残った理由」

NG例（参考、本チャンネルでは使わない）:
- 「最強の肉食恐竜ランキング」「衝撃のティラノ生態」「ヤバすぎる古代生物」等
- 「ティラノサウルスの新たな生態解釈」「2026年の新発見」のように学術論文タイトル直訳系も、雑学トーンとしては硬すぎるため避ける（情報としては盛り込むが、タイトル文言には出さない）
