# チャンネルコンセプト

## チャンネル名
（仮）`20代マネー並走（仮）` / 候補: 「並走マネー」「30前マネーラボ」「数字で語る投資ノート」など
→ manami/hinaに正式候補を3-5案出してもらい、なーたん最終判断。

## 一言で言うと
同年代の少し先を行く先輩が、煽らずに並走する20代-30代前半向け投資チャンネル。

## なぜ作るのか（Why）
- **市場機会**:
  - 新NISA以降、20代の証券口座開設数は急増したが、faceless × 20代向け × 投資 はまだ薄い領域。
  - 顔出し競合（両学長、ぽんちよ等）は40代以降を中心に押さえているが、「20代の現実的な数字で語る並走系」は空いている。
  - 口座アフィリ・クレカアフィリのコンバージョンが高く、広告RPM低下を補える試算。
- **自分たちが勝てる理由**:
  - 非属人だからこそ「中立的なシナリオ比較」が説得力を持つ（個人の自慢にならない）。
  - AI音声＋図解＋独自試算で、Inauthenticポリシー回避と量産の両立が可能。
  - チーム4人体制で台本・映像・編集・サムネを分担、月8本ペースが現実的。

## 何を届けるのか（What）
- **主コンテンツ**: 25-34歳の「始め方・失敗回避・同年代比較」を、独自シミュレーションと図解で淡々と解説。
- **サブコンテンツ**: 22-26歳向けの「口座開設・最初の1万円」入門シリーズ。

## どう作るのか（How / 非属人性）
- **動画フォーマット**: AI音声ナレーション + テロップ + 図解・グラフ画像 + Seedance生成のBロール（街・オフィス等の抽象映像）
- **制作パイプライン**: manami台本 → junki音声合成（Fish Audio） → nishi映像（Seedance + 図解素材） → junki編集 → hinaサムネ → yutaka最終チェック → なーたん承認 → 公開
- **想定制作工数 / 本**: 立ち上げ初期は1本あたり総工数20-30時間。慣れたら15時間以内に圧縮。
- **尺**: 8-10分

## 差別化ポイント
- **競合**:
  - 顔出し系: 両学長（240万）、バフェッ太郎、ぽんちよ、楽天証券トウシル
  - Faceless系: 既存の投資解説チャンネルは40-50代向けが多い
- **自分たちのエッジ**:
  - 「同年代の数字で語る」（25歳年収400万のリアルなポートフォリオ等）
  - 「失敗回避特化」（勝ち方より避け方）
  - 「個別銘柄推奨しない代わりにシナリオを示す」
  - 「編集判断ログを残す」（Inauthentic判定対策の独自運用）

## 収益化シナリオ
- **メイン**: 広告25% / 口座アフィリ35% / クレカ・家計簿20% / 書籍10% / メンバーシップ案件10%
- **想定単価・規模**:
  - 1本平均10万再生で、広告5-7万円 + アフィリ流入次第で+5-10万円
  - 月8本ペースで3-6ヶ月後、月収益10-30万円が初期ターゲット

## 量産可能性
- **同一フォーマットでの想定本数 / 月**: 8本（A群3 / B群2 / C群1 / D群1 / E群1）
- **横展開チャンネルの可能性**:
  - 「30代後半-40代向け」スピンオフ（住宅・教育費連動）
  - ~~「英語版・海外投資家向け」（恐竜チャンネルで英語運用ナレッジが溜まり次第）~~ **【2026-06-02 なーたん指示により一旦保留】** 全チャンネルで英語版展開は当面停止。日本語運用に集中。将来再開の可能性は残置。

## リスク
- **ポリシー**: 投資助言扱いされる表現は完全NG。毎本ガードレール遵守。
- **著作権**: 引用データ（金融庁・投信協会・各社IR）は出典明記必須。サムネで企業ロゴ使用時は要注意。
- **飽き / 持続性**: A群「始め方系」だけだと半年でネタ枯れ → B群（比較データ）と C群（失敗事例）を早期に育てる。
