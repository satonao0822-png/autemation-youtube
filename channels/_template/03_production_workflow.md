## 品質チェックリスト（公開前）
- [ ] 冒頭15秒のフックは十分強いか
- [ ] 音量レベルは適切か
- [ ] 字幕の誤字脱字
- [ ] サムネとタイトルの整合性
- [ ] 概要欄のリンク・タイムスタンプ
- [ ] 著作権チェック（BGM・素材・引用）
- [ ] AI生成物の利用規約クリア
- [ ] タグ・カテゴリ・終了画面・カード

- 分析メモ: `analytics/EP{NN}_{slug}_{YYYY-MM-DD}.md`
