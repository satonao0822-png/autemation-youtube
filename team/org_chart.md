# チーム組織図

> 非属人YouTubeチャンネル運用チームの編成。ADR-001 / ADR-002 / ADR-005 をベースに、命名規則（`team/naming_convention.md`）に従って役割名で表記。

## 階層図

```
なーたん（プロジェクトオーナー / 意思決定者）
   ⇅
yutaka（YouTubeプロジェクト責任者 / 戦略・対外）
   ├── 投資チャンネルPM（invest-pm）       ┐
   │     担当: channels/channel_01_invest_youth/
   │
   └── 恐竜チャンネルPM（dinosaur-pm）     ├─ 各PMが下記4人を職能横断で使う
         担当: channels/channel_02_dinosaur/

職能メンバー（チャンネル横断・PMから依頼を受ける）
   ├── manami（YouTube作家・台本）
   ├── nishi（映像クリエイター）
   ├── junki（編集・音声合成）
   └── hina（サムネ・タイトル）
```

横の矢印（ピア）: manami ⇄ nishi ⇄ junki ⇄ hina は互いに `Agent` で直接呼び合える。`team/communication_protocol.md` 参照。

| レイヤー | 呼称 | 命名タイプ | 主な責任 |
| --- | --- | --- | --- |
| 0. 決裁 | なーたん | 個人名 | リソース配分・最終ゴーサイン・戦略の入れ替え |
| 1. 戦略責任者 | yutaka | 個人名 | チャンネル横断戦略・収益構造・対外（なーたん報告）・ADR起案 |
| 2. チャンネル別PM | 投資チャンネルPM / 恐竜チャンネルPM | 役割名 | 担当チャンネルの現場運営・編集ガードレール・KPI監視・チーム内タスク捌き |

命名規則の詳細（個人名と役割名を混在させている理由・slug対応表）は `team/naming_convention.md` を参照。

## PMレイヤー新設の趣旨（ADR-005）

- 投資チャンネルと恐竜チャンネルは**動画の作り方・運用ノウハウが本質的に異なる**ため、yutakaが両方を兼務PM化するとガードレールがブレる。
- 投資チャンネルPM = 金融広告コンプラ・口座アフィリ導線設計に強い現場PM
- 恐竜チャンネルPM = 学術精度・長期ライブラリ・英語版展開に強い現場PM
- yutakaは「戦略・対外・なーたん窓口」に専念。日々の進行管理は各PMに委譲。
- 詳細は `decisions/ADR-005_channel_pm_layer.md`。

## エスカレーションパス

- 職能メンバー → 担当チャンネルPM（投資チャンネルPM or 恐竜チャンネルPM） → yutaka → なーたん
- メンバー間で結論が割れた場合のみPMが介入。PMで判断できない戦略・予算事案だけがyutakaに上がる。
- なーたんが直接特定メンバーを指名した場合は直答 OK（事後にPM/yutakaへ共有）。
