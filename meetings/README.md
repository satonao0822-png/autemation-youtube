# meetings — 議事録

## ファイル命名
`YYYY-MM-DD_topic.md`

例: `2026-06-01_kickoff.md`

## 日次フロー（Notion HQ 連携）

1. **日中**: 議論があったらこのフォルダに議事録を書く（正本）
2. **1日1回・終業時**: Claude に `日次報告を更新して` と依頼
3. Notion **[日次HQレポート](https://www.notion.so/4dc69eca0d454576b585d4ff1ee332d5)** に要約を反映
4. [非属人YouTube HQ](https://www.notion.so/3729aee02088813a9b5fc24894468629) 先頭の **📣 なーたんへの今日の活動内容報告** で確認

詳細: `knowledge/daily_hq_briefing_flow.md`
