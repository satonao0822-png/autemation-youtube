## 議論

### 1. 経緯（時系列）

#### 1-1. 依頼書送付（2026-06-01）

- 恐竜チャンネルPM → hina へチャンネル名提案を依頼（`_request_to_hina_2026-06-01.md`）。
- **依頼書の前提固定が問題だった**: PM側が「学術寄り・BBC Earth系・しっとり詩情」を絶対前提として依頼書を書いた。`01_target_persona.md` の「BBC Earth、National Geographic」記述に引きずられていた。
- 一方、`_pm_memo_ep01_longlist.md`（EP01テーマ決裁時）には「**もっと知りたいと思わせる雑学系の余韻**」が最重要キーワードとして明示されていた。**この方向修正シグナルを依頼書に反映できていなかった**のがそもそもの起点。

#### 1-2. hina v1 提案

- hina から13案 + 第4案「古生物夜想 / Paleo Nocturne」+ TOP3 提示。
- TOP3:
  1. **古生物図譜 / The Paleo Folio**（方向B-5、渋さの極）
  2. **痕跡の地球 / Traces of Earth**（方向C-1、射程の広さ）
  3. **古生物手帖 / Paleo Field Notes**（方向B-1、日英ペアの完成度）
- **全体として「渋い学術寄り路線」**に振れた提案構成。依頼書の前提を素直に受けたため当然の帰結。

#### 1-3. なーたん対抗案

- なーたん「**古代生物のふしぎな世界【おやすみ前の大人雑学】**」を提示。
- 視聴シーン設計（おやすみ前）と雑学ポジション（大人雑学）を1つの名前にまとめた構造。

#### 1-4. PM と hina の一次評価（前提誤認のまま）

学術寄りBBC Earth系を絶対前提にしたまま、なーたん原案に4つのNG指摘:

| 指摘 | 内容 |
| --- | --- |
| (a) | 「ふしぎ」は子供向け語彙、大人向けポジションを毀損する |
| (b) | 【】の補足構造で本タイトルが弱い |
| (c) | 17文字（フル長20文字超）でスマホ表示・サムネ表示で省略される |
| (d) | 「古代生物」は語精度が弱い（学術的には「古生物」が正確） |

→ この時点で、PM と hina ともに「自分たちが正しく、なーたん原案を直すべき」という構えになっていた。

#### 1-5. なーたん方向修正発言

- なーたん「**何もアカデミック寄りにしたいわけじゃないんだよな。あくまで大人の雑学系。**」
- この一文で前提が一気に裏返る。`_pm_memo_ep01_longlist.md` で出ていた「もっと知りたい雑学系の余韻」シグナルと整合する真の方向性が明示された。

#### 1-6. PM・hina の前提誤認認知

- hina が v2 として「13案 + TOP3 の再評価 + v2新案5案」を提出（`_proposal_from_hina_channel_name.md` 末尾）。
- **重要な認知改め**:
  - v1 TOP3（B-5 図譜・C-1 痕跡・B-1 手帖）はいずれも新前提「大人雑学系」では**初動で苦しい**と hina 自己判定 → 圏外〜中評価に降格。
  - なーたん原案の(a)指摘「ふしぎは子供向け語彙」は**前提誤認による誤判定**として撤回。新前提では「ふしぎ」は積極的に使ってOKの解禁語彙。
  - 第4案「古生物夜想 / Paleo Nocturne」も渋路線の産物として撤回寄り。
- v2新案5案:
  - v2-1: 古生物のふしぎ / Paleo Curiosities
  - v2-2: 古生物雑学ノート / Paleo Trivia Notes
  - v2-3: もっと知りたい古生物 / The Paleo Curious
  - v2-4: 古生物のふしぎ図鑑 / Paleo Wonder Book
  - v2-5: 古生物ふしぎ夜話 / Paleo Night Stories
- hina v2 TOP3 推奨: v2-1（hina本命）／ v2-2 ／ v2-5

#### 1-7. 最終決裁（なーたん）

- v2新案ではなく、**なーたん原案ベース**で確定。
- 採用: **「古代生物のふしぎな世界」**（シーン宣言「おやすみ前の大人雑学」は本タイトルから外す）
- シーン宣言の扱い: **概要欄/サムネ運用に降ろす**（PM案④採用）
- 英語版チャンネル名: 本決裁では確定しない。直訳ではなく英語圏で独立成立する名前を別途検討、hina に後日改めて依頼予定
- ADR-006 起案 GO

### 2. 論点別の議論内容

#### 2-1. なぜ依頼書の前提を間違えたか（PM側の反省）

- `01_target_persona.md` の「BBC Earth、National Geographic」記述を絶対前提として固定し、その後の方向修正シグナル（`_pm_memo_ep01_longlist.md` の「もっと知りたい雑学系の余韻」）を依頼書に反映できなかった。
- 結果、hina に渡した依頼書が「学術寄り・しっとり系」固定で、hina の v1 13案がその方向に偏った。
- **教訓**: 依頼書を書く時、最新の方向修正シグナル（PMメモ・EP決裁等）と既存ドキュメント（01_target_persona.md 等）に齟齬がある場合、**最新シグナルを優先**して依頼書に反映する。古いドキュメントは別ターンで書き換える。

#### 2-2. なーたん原案ベースに戻った理由

- hina v2新案（v2-1 古生物のふしぎ / Paleo Curiosities など）は、雑学路線への振り直しとしては正しいが、**なーたんの語感（おやすみ前・大人雑学）を捨てる方向**だった。
- なーたん原案「古代生物のふしぎな世界」は、(b)冗長・(c)長さの問題が残るが、シーン宣言を本タイトルから外して概要欄/サムネ運用に降ろせば解決する。
- **「なーたんの語感をどこまで尊重するか」を最優先**して、原案ベースを採用。

#### 2-3. 「古代生物」vs「古生物」

- 学術精度では「古生物」が正確。
- ただし本ADR-006で「大人の雑学系」に振り直す方針を採るため、**親しみ寄りの「古代生物」のほうがチャンネル名として整合**する。
- 動画本編・概要欄では「古生物」「古生物学」も適宜併用してOK（コアファン向けの語精度は本編内で担保）。

#### 2-4. シーン宣言を概要欄/サムネ運用に降ろす意義

- 「おやすみ前」というシーン設計の発想自体は強い（hina v2-5 で「夜話」案の核としても評価されている）。
- ただしチャンネル名本体に【】補足で組み込むと、長さで省略される問題が残る。
- シーン宣言は**概要欄の冒頭1行**と**サムネ枠デザインのサブコピー**で運用上活かす。チャンネル名本体は短く保つ。

#### 2-5. 学術精度との両立

- 雑学化したのは**語彙・トーン・親しみ感**であって、**ファクトの精度ではない**ことをチーム共有の前提として明文化。
- 推測・仮説は「〜と考えられている」「〜という説がある」と明示、最上級表現には限定詞、一次情報優先のルールは維持。
- 監修者契約の検討も継続。

---

## 決まったこと

1. **トーン方針の軌道修正**: ADR-003で定義した「学術寄り・しっとり系・BBC Earth系」から「**大人の雑学系**（学術寄りでもナゾロジー系でもない中間）」へ。
2. **チャンネル名確定**: **古代生物のふしぎな世界**
3. **シーン宣言の扱い**: 「おやすみ前の大人雑学」はチャンネル名本体に含めず、**概要欄/サムネ運用に降ろす**（PM案④採用）
4. **英語版チャンネル名**: 本決裁では保留。直訳ではなく英語圏で独立成立する名前を別途検討、hinaに後日改めて依頼
5. **学術精度の運用ルール**: 雑学化と両立。一次情報優先・推測の明示・最上級限定詞の運用は維持
6. **ADR-006 起案**: 上記を正式決定として記録（2026-06-02付け）
